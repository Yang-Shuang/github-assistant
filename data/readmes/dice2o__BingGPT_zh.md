## 使用方法

- 登录你的微软账号
- 开始聊天

**注意：如果你的所在地区无法访问新版必应，需要使用代理（VPN）。请确保在代理规则中已添加 `bing.com` 及其子域名。**

**如果在 macOS 上无法打开该应用，请在“终端”应用中执行以下命令：**

```
sudo xattr -d com.apple.quarantine /Applications/BingGPT.app
```

## 功能特性

- 无需安装 Microsoft Edge 或浏览器插件，即可与新版必应对话
- 支持将完整聊天记录导出为 Markdown、PNG 或 PDF 格式
- 自定义外观（主题与字体大小）
- 支持键盘快捷键
- 跨平台支持

## 快捷键

| 操作            | 快捷键                                        |
| ----------------- | ----------------------------------------------- |
| 新建话题         | <kbd>Ctrl/Cmd</kbd> + <kbd>N</kbd>              |
| 切换语气       | <kbd>Ctrl/Cmd</kbd> + <kbd><</kbd> <kbd>></kbd> |
| 快捷回复       | <kbd>Ctrl/Cmd</kbd> + <kbd>数字键</kbd>         |
| 聚焦输入框 | <kbd>Ctrl/Cmd</kbd> + <kbd>I</kbd>              |
| 停止响应   | <kbd>Ctrl/Cmd</kbd> + <kbd>S</kbd>              |
| 窗口置顶     | <kbd>Ctrl/Cmd</kbd> + <kbd>T</kbd>              |
| 刷新            | <kbd>Ctrl/Cmd</kbd> + <kbd>R</kbd>              |
| 调整字体大小     | <kbd>Ctrl/Cmd</kbd> + <kbd>+</kbd> <kbd>-</kbd> |

<kbd>Ctrl</kbd> - Windows 和 Linux

<kbd>Cmd(⌘)</kbd> - macOS

## 适合人群

- **完全零基础新手**：先做出第一个项目，再理解它是如何工作的
- **产品经理 / 创始人**：快速验证想法，低成本构建 MVP（最小可行性产品）
- **在校学生**：掌握 AI 时代所需的实战技能
- **初级开发者**：学习从灵感到上线的完整路径
- **中级与高级开发者**：升级复杂项目中的 AI 协同工作流



## 你的学习路径

### 🎮 我想快速获得第一次成功体验
**适合人群**：所有人
**你将学到**：通过一个简单具体的实操案例，亲身体验什么是真正的 Vibe Coding（AI 辅助编程）
**你将获得**：对 AI 协作编程的清晰第一印象，以及通过对话与 AI 协同工作的方法

[从这里开始](https://datawhalechina.github.io/easy-vibe/en/stage-1/ai-capabilities-through-games/)

### 💡 我想把想法变成产品原型
**适合人群**：新手 / 产品经理 / 创始人
**你将学到**：学习路线、AI IDE 工具、需求验证、原型设计、AI 能力集成与完整 Demo 迭代
**你将获得**：一个可实际演示给用户或团队成员看的 AI 产品原型

[开始学习](https://datawhalechina.github.io/easy-vibe/en/stage-1/learning-map/)

### 🚀 我想端到端构建全栈产品
**适合人群**：初级开发者 / 独立开发者 / 进阶学习者
**你将学到**：前端工作流、设计转代码（Design-to-code）、数据库、后端 API、部署、计费与综合项目
**你将获得**：独立交付现代 AI 赋能 Web 应用的能力

[开始学习](https://datawhalechina.github.io/easy-vibe/en/stage-2/)

### AI-Native：我想掌握高级 Claude Code 与 Agent 工作流
**适合人群**：对 AI 原生工程感兴趣的开发者
**你将学到**：Claude Code、MCP（模型上下文协议）、Skills（技能包）、Agent Teams（智能体团队）、长时任务、Spec Coding（规范驱动开发）与跨平台应用交付
**你将获得**：更强大的复杂 AI 辅助开发与自动化工作流

[前往进阶开发](https://datawhalechina.github.io/easy-vibe/en/stage-3/)

### 📚 我需要参考资料与基础知识
**适合人群**：所有人
**你将学到**：计算机基础、前后端基础、基础设施、AI 原理与工程实践
**你将获得**：覆盖 9 大知识领域的长期参考知识库

[浏览知识库](https://datawhalechina.github.io/easy-vibe/en/appendix/)

## 学习建议

- 如果你是新手、产品经理或创始人，请从 [第一阶段](https://datawhalechina.github.io/easy-vibe/en/stage-1/learning-map/) 开始
- 如果你想从原型过渡到全栈交付，请从 [第二阶段](https://datawhalechina.github.io/easy-vibe/en/stage-2/) 开始
- 如果你需要高级 Claude Code 工作流或跨平台项目，请访问 [第三阶段](https://datawhalechina.github.io/easy-vibe/en/stage-3/)
- 如果你在概念或背景知识上受阻，请使用[附录知识库](https://datawhalechina.github.io/easy-vibe/en/appendix/)

## 💻 本地运行

### 现代化方式

在 VS Code、Cursor 或 Trae 等 AI IDE 的聊天窗口中，你只需输入：

```text
Please help me run this project locally.
```

### 传统方式

1. `npm install`
2. `npm run dev`
3. 在浏览器中打开 `http://localhost:3000`。

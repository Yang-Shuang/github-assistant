## 协助翻译

请注册 Crowdin 并加入我们的[Crowdin 项目](https://crowdin.com/project/linearmouse)，将 LinearMouse 翻译为支持的语言。建议使用 GitHub 账号登录 Crowdin，以便我在合并 Pull Request 时将你添加为共同作者（co-author）。

如需新增支持的语言，请[创建新 Issue](https://github.com/linearmouse/linearmouse/issues/new)，我将很乐意为你启用该语言的翻译权限。

我的英语并非母语，如果你发现任何英文本地化问题，欢迎通过[创建 Pull Request](https://github.com/linearmouse/linearmouse/edit/main/LinearMouse/en.lproj/Localizable.strings) 直接修正。

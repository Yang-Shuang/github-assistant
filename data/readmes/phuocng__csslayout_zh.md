# CSS 布局

作为一名前端工程师，我经常需要处理各种布局和组件。虽然市面上有许多提供这些功能的 CSS 框架，但我并不总是希望将它们全部引入到项目中。

因此，我整理了一份使用纯 CSS 即可实现的流行布局与组件合集。

这些布局与组件基于 Flexbox（弹性盒子）和 Grid（网格布局）等现代 CSS 特性构建，能够轻松定制以满足你的具体需求。通过组合使用它们，你可以实现任何所需的页面结构。

最棒的是？该合集零依赖、无框架引入，也不包含任何 CSS Hack（技巧）。这些都是经过验证的实际应用场景，能够帮你节省项目中的时间与精力。

## 💡 简介

欢迎使用 **Agent S**，这是一个开源框架，旨在通过智能体-计算机接口（Agent-Computer Interface）实现与计算机的自主交互。我们的使命是构建能够通过学习过往经验并自动执行复杂任务的智能 GUI 智能体。 

无论你是对人工智能、自动化感兴趣，还是希望为前沿的智能体系统做出贡献，我们都热烈欢迎你的加入！

## 🎯 当前结果

<p align="center">
  <img src="images/s3_results_new.png" alt="Agent S3 Results" width="700"/>
</p>

在 OSWorld 上，仅凭 Agent S3 自身即可在 100 步设置下达到 66%，已超越此前的 SOTA（GTA1 w/ GPT-5）的 63.4%。结合 Behavior Best-of-N (BBoN) 技术后，性能进一步提升至 72.6%，*成功超越*了 OSWorld 上的人类水平性能（约 72%）！

Agent S3 还展现出强大的零样本泛化能力！在 WindowsAgentArena 上，仅使用 Agent S3 准确率为 50.2%，通过从 3 次运行中选择最佳结果可提升至 56.6%。同样在 AndroidWorld 上，性能也从 68.1% 提升到了 71.6%。

## 🛠️ 安装与配置

### 前置条件
- **单显示器**：我们的智能体专为单显示器屏幕设计
- **安全性**：该智能体会运行 Python 代码来控制你的计算机——请谨慎使用
- **支持平台**：Linux、Mac 和 Windows


### 安装
若不想克隆仓库即可安装 Agent S3，请运行：
```bash
pip install gui-agents
```
如果你希望在修改代码的同时测试 Agent S3，可克隆仓库并使用以下命令安装：
```
pip install -e .
```

别忘了运行 `brew install tesseract`！Pytesseract 需要此项额外依赖才能正常工作。

### API 配置

#### 方式一：环境变量
添加到你的 `.bashrc`（Linux）或 `.zshrc`（MacOS）中：
```bash
export OPENAI_API_KEY=<YOUR_API_KEY>
export ANTHROPIC_API_KEY=<YOUR_ANTHROPIC_API_KEY>
export HF_TOKEN=<YOUR_HF_TOKEN>
```

#### 方式二：Python 脚本
```python
import os
os.environ["OPENAI_API_KEY"] = "<YOUR_API_KEY>"
```

### 支持的模型
我们支持 Azure OpenAI、Anthropic、Gemini、OpenRouter 和 vLLM 推理。详见 [models.md](models.md)。

### 定位（Grounding）模型（必需）
为获得最佳性能，我们推荐使用托管在 Hugging Face Inference Endpoints 或其他提供商处的 [UI-TARS-1.5-7B](https://huggingface.co/ByteDance-Seed/UI-TARS-1.5-7B)。详见 [Hugging Face Inference Endpoints](https://huggingface.co/learn/cookbook/en/enterprise_dedicated_endpoints) 获取配置指南。

## 🚀 使用方法


> ⚡️ **推荐配置：**  
> 为获得最佳效果，我们建议使用 **OpenAI gpt-5-2025-08-07** 作为主模型，并搭配 **UI-TARS-1.5-7B** 进行定位。  


### CLI

注意：此处运行的是 Agent S3（我们的改进版智能体），未启用 BBoN。

使用必需参数运行 Agent S3：

```bash
agent_s \
    --provider openai \
    --model gpt-5-2025-08-07 \
    --ground_provider huggingface \
    --ground_url http://localhost:8080 \
    --ground_model ui-tars-1.5-7b \
    --grounding_width 1920 \
    --grounding_height 1080
```

#### 本地编码环境（可选）
对于需要代码执行的任务（例如数据处理、文件操作、系统自动化），你可以启用本地编码环境：

```bash
agent_s \
    --provider openai \
    --model gpt-5-2025-08-07 \
    --ground_provider huggingface \
    --ground_url http://localhost:8080 \
    --ground_model ui-tars-1.5-7b \
    --grounding_width 1920 \
    --grounding_height 1080 \
    --enable_local_env
```

⚠️ **警告**：本地编码环境会在你的机器上直接执行任意 Python 和 Bash 代码。仅在可信环境中使用此功能，并确保输入内容安全。

#### 必需参数
- **`--provider`**：主生成模型提供商（例如 openai、anthropic 等）- 默认值："openai"
- **`--model`**：主生成模型名称（例如 gpt-5-2025-08-07）- 默认值："gpt-5-2025-08-07"
- **`--ground_provider`**：定位模型的提供商 - **必需**
- **`--ground_url`**：定位模型的服务地址 - **必需**
- **`--ground_model`**：定位模型的名称 - **必需**
- **`--grounding_width`**：定位模型输出的坐标分辨率宽度 - **必需**
- **`--grounding_height`**：定位模型输出的坐标分辨率高度 - **必需**

#### 可选参数
- **`--model_temperature`**：固定所有模型调用的温度值（对于 o3 等模型需设为 1.0，其他模型可留空）

#### 定位模型尺寸要求
定位模型的宽度和高度应与你的定位模型输出的坐标分辨率匹配：
- **UI-TARS-1.5-7B**：使用 `--grounding_width 1920 --grounding_height 1080`
- **UI-TARS-72B**：使用 `--grounding_width 1000 --grounding_height 1000`

#### 更多可选参数
- **`--model_url`**：主生成模型的自定义 API 地址 - 默认值：""
- **`--model_api_key`**：主生成模型的 API Key - 默认值：""
- **`--ground_api_key`**：定位模型端点的 API Key - 默认值：""
- **`--max_trajectory_length`**：轨迹中保留的最大图像轮数 - 默认值：8
- **`--enable_reflection`**：启用反思智能体辅助工作智能体 - 默认值：True
- **`--enable_local_env`**：启用本地编码环境用于代码执行（警告：会在本地执行任意代码）- 默认值：False

#### 本地编码环境详情
启用后，Agent S3 可直接在你的机器上执行 Python 和 Bash 代码。这特别适用于以下场景：

- **数据处理**：操作电子表格、CSV 文件或数据库
- **文件操作**：批量处理文件、内容提取或文件整理
- **系统自动化**：配置更改、环境搭建或自动化脚本运行
- **代码开发**：编写、编辑或执行代码文件
- **文本处理**：文档操作、内容编辑或格式调整

启用后，智能体可使用 `call_code_agent` 动作来执行代码块，适用于可通过编程而非 GUI 交互完成的任务。

**环境要求：**
- **Python**：运行 Agent S3 所使用的同一 Python 解释器（自动检测）
- **Bash**：位于 `/bin/bash`（macOS 和 Linux 标准路径）
- **系统权限**：智能体将以执行用户的相同权限运行

**安全注意事项：**
- 本地环境会以与运行智能体的用户相同的权限执行任意代码
- 仅在可信环境中启用此功能
- 当智能体生成涉及系统级操作的代码时请保持警惕
- 对于不可信的任务，建议考虑在沙盒环境中运行
- Bash 脚本执行设有 30 秒超时限制，以防止进程挂起

### `gui_agents` SDK

首先导入必要的模块。`AgentS3` 是 Agent S3 的主智能体类。`OSWorldACI` 是我们的定位智能体，负责将智能体操作转换为可执行的 Python 代码。
```python
import pyautogui
import io
from gui_agents.s3.agents.agent_s import AgentS3
from gui_agents.s3.agents.grounding import OSWorldACI
from gui_agents.s3.utils.local_env import LocalEnv  # Optional: for local coding environment

# Load in your API keys.
from dotenv import load_dotenv
load_dotenv()

current_platform = "linux"  # "darwin", "windows"
```

接下来定义引擎参数。`engine_params` 用于主智能体，`engine_params_for_grounding` 用于定位模型。对于 `engine_params_for_grounding`，我们支持自定义端点（如 HuggingFace TGI、vLLM 和 OpenRouter）。

```python
engine_params = {
  "engine_type": provider,
  "model": model,
  "base_url": model_url,           # Optional
  "api_key": model_api_key,        # Optional
  "temperature": model_temperature # Optional
}

# Load the grounding engine from a custom endpoint
ground_provider = "<your_ground_provider>"
ground_url = "<your_ground_url>"
ground_model = "<your_ground_model>"
ground_api_key = "<your_ground_api_key>"

# Set grounding dimensions based on your model's output coordinate resolution
# UI-TARS-1.5-7B: grounding_width=1920, grounding_height=1080
# UI-TARS-72B: grounding_width=1000, grounding_height=1000
grounding_width = 1920  # Width of output coordinate resolution
grounding_height = 1080  # Height of output coordinate resolution

engine_params_for_grounding = {
  "engine_type": ground_provider,
  "model": ground_model,
  "base_url": ground_url,
  "api_key": ground_api_key,  # Optional
  "grounding_width": grounding_width,
  "grounding_height": grounding_height,
}
```

然后定义定位智能体和 Agent S3。

```python
# Optional: Enable local coding environment
enable_local_env = False  # Set to True to enable local code execution
local_env = LocalEnv() if enable_local_env else None

grounding_agent = OSWorldACI(
    env=local_env,  # Pass local_env for code execution capability
    platform=current_platform,
    engine_params_for_generation=engine_params,
    engine_params_for_grounding=engine_params_for_grounding,
    width=1920,  # Optional: screen width
    height=1080  # Optional: screen height
)

agent = AgentS3(
    engine_params,
    grounding_agent,
    platform=current_platform,
    max_trajectory_length=8,  # Optional: maximum image turns to keep
    enable_reflection=True     # Optional: enable reflection agent
)
```

最后，向智能体发送指令！

```python
# Get screenshot.
screenshot = pyautogui.screenshot()
buffered = io.BytesIO() 
screenshot.save(buffered, format="PNG")
screenshot_bytes = buffered.getvalue()

obs = {
  "screenshot": screenshot_bytes,
}

instruction = "Close VS Code"
info, action = agent.predict(instruction=instruction, observation=obs)

exec(action[0])
```

有关推理循环的详细实现，请参考 `gui_agents/s3/cli_app.py`。

<h3 align="center">快速开始</h3>

```sh
pip install -U cocoindex
```

声明目标中应包含的*内容*——CocoIndex 将永久保持同步，仅重新计算增量（Δ）。

```python
import cocoindex as coco
from cocoindex.connectors import localfs, postgres
from cocoindex.ops.text import RecursiveSplitter

@coco.fn(memo=True)                          # ← cached by hash(input) + hash(code)
async def index_file(file, table):
    for chunk in RecursiveSplitter().split(await file.read_text()):
        table.declare_row(text=chunk.text, embedding=embed(chunk.text))

@coco.fn
async def main(src):
    table = await postgres.mount_table_target(PG, table_name="docs")
    table.declare_vector_index(column="embedding")
    await coco.mount_each(index_file, localfs.walk_dir(src).items(), table)

coco.App(coco.AppConfig(name="docs"), main, src="./docs").update_blocking()
```

<p align="center">首次运行进行数据回填。随时可再次运行——仅对变更文件重新生成嵌入向量。</p>

<h3 align="center">大规模语料库 ——<em>专为企事业规模打造。</em></h3>

<p align="center">
  增量计算是让大型语料库保持更新而无需每轮重新生成嵌入的唯一方式。<br/>
  CocoIndex 支持从单个仓库到 PB 级存储的扩展——默认并行，设计即为仅处理增量。
</p>

<br/>

<h3 align="center">一次处理。<em>永久同步。</em></h3>

<p align="center">
  当数据源发生变更时，CocoIndex 会精准识别受影响的记录，将变更传播<br/>
  至关联查询中，更新目标存储并清理过时行——<br/>
  绝不触碰任何未变动的内容。
</p>

<br/>

<h3 align="center">基于 <em>Rust 引擎</em>构建。</h3>

<p align="center">
  核心采用 Rust —— 从第一天起就具备生产级标准。<br/>
  支持并行分块、尽可能实现零拷贝转换，以及故障隔离机制——<br/>
  确保单条异常记录不会阻塞整个数据流。
</p>

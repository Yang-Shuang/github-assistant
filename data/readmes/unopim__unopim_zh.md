UnoPim 是一款基于 Laravel 12 构建的开源产品信息管理（Product Information Management，简称 PIM）系统。它帮助企业在一个中央存储库中组织、管理和丰富产品信息——现已内置 AI Agent 功能，支持通过对话式交互进行产品管理。

## ✨ 功能特性

- **AI Agent 对话**
  通过自然语言管理产品——支持搜索、创建、更新、批量编辑、导出、分类，并通过多步工具调用的对话式 AI 生成内容。
    <p><img src="https://raw.githubusercontent.com/unopim/temp-media/main/ai-agent-chat.png" alt="AI Agent Chat" width="720"></p>
    
- **跨平台 Magic AI**
  使用 10 多家 AI 服务商生成产品内容、图片和翻译。支持加密凭证存储、连接测试和动态模型选择，方便配置与管理各 AI 平台。
  <p><img src="https://raw.githubusercontent.com/unopim/temp-media/main/magic-ai-with-multi-platform-support.png" alt="Magic AI with Multi-Platform Support" width="720"></p>

- **高级 AI 驱动的产品管理**
    借助智能自动化创建吸引人的产品内容、生成高质量图片并获取可操作的洞察。利用可自定义的数据面板、无缝的多用户协作和智能报表工具，优化工作流并提升全平台生产力。
  <p><img src="https://raw.githubusercontent.com/unopim/temp-media/main/advanced-features.png" alt="AI-powered Product Content Generation" width="720"></p>

- **集中式产品管理**
  在一个地方统一管理所有产品数据。

  <p><img src="https://raw.githubusercontent.com/unopim/temp-media/main/catalog-management.png" alt="Centralized Product Management Interface" width="720"></p>

- **数据丰富化**
  通过详细的属性和描述增强产品信息。

  <p><img src="https://raw.githubusercontent.com/unopim/temp-media/main/data-enrichment.png" alt="Data Enrichment Interface" width="720"></p>

- **数据分析面板**
  一目了然地监控渠道就绪状态、产品趋势、近期活动及需关注的项目。

    <p><img src="https://raw.githubusercontent.com/unopim/temp-media/main/dashboard-with-analytics.png" alt="Dashboard with Analytics" width="720"></p>
    
- **用户管理**
  控制用户访问权限与操作许可。

  <p><img src="https://raw.githubusercontent.com/unopim/temp-media/main/access-control.png" alt="User Management Interface" width="720"></p>

- **API 集成**
  通过 RESTful API 与其他系统无缝集成。可导入官方 [Postman 集合](https://www.postman.com/unopim/unopim-apis/collection/kzy03uh/official-unopim-apis?ctx=info) 或浏览[完整 API 文档](https://documenter.getpostman.com/view/37137259/2sBXVhEWjS)。

- **本地化支持**
  开箱即用，原生支持 33 种语言和地区设置。

  <p><img src="https://raw.githubusercontent.com/unopim/temp-media/main/localization-and-channels.png" alt="Localization Support" width="720"></p>

  <p><img src="https://raw.githubusercontent.com/unopim/temp-media/main/multi-channel-support.png" alt="Multi-Channel Support" width="720"></p>

## 🚀 安装指南

> **环境要求：** Nginx/Apache2、PHP 8.3+、Node 20 LTS+、Composer 2.5+，以及 MySQL 8.0.32+ 或 PostgreSQL 14+（*推荐*）。

完整 [安装指南](https://devdocs.unopim.com/2.0.x/introduction/installation.html) 请参阅 devdocs —— 或直接选择以下快速路径。

### Composer

```bash
composer create-project unopim/unopim
cd unopim
php artisan unopim:install
php artisan serve
```

在浏览器中访问 `http://localhost:8000`。要执行导入/导出、AI Agent 任务、完整性检查作业和 Webhook 投递，请启动队列工作者：

```bash
php artisan queue:work --queue=webhooks,system,default,completeness
```

> **注意：** 发送 Webhook 需要启用 `webhooks` 队列。`Webkul\Webhook\Listeners\Product` 监听器会异步分发至该队列，因此产品保存/更新请求不会被对订阅者的 HTTP 调用阻塞。若你在 `--queue` 参数中省略了 `webhooks`，Webhook 事件将堆积但永远不会被处理。

### Docker

需要 Docker + Docker Compose v2+。高级配置请参阅完整 [Docker 指南](https://devdocs.unopim.com/2.0.x/introduction/installation.html#install-using-docker)。

```bash
git clone https://github.com/unopim/unopim.git
cd unopim
cp .env.docker .env
docker compose up -d
```

等待约 90 秒完成首次数据库迁移与数据填充，随后访问 `http://localhost:8000/admin` 并使用 `admin@example.com` / `admin123` 登录。

**Apache 替代方案**（不使用 Nginx）：

```bash
docker compose -f docker-compose.yml -f docker-compose.apache.yml up -d
```

> **端口冲突？** 若你本地已运行 MySQL、Redis 或 Elasticsearch，请编辑 `.env` 中的 `FORWARD_*` 端口并重启。详见 `.env.docker` 文件说明。

## 课程内容

课程共分为 4 个单元。你将**从 Agent 基础开始，逐步完成结合基准测试的最终作业**。

在此注册（免费）👉 <a href="https://bit.ly/hf-learn-agents" target="_blank">https://bit.ly/hf-learn-agents</a>

访问课程 👉 <a href="https://hf.co/learn/agents-course" target="_blank">https://hf.co/learn/agents-course</a>

| 单元 | 主题 | 说明 |
|---|---|---|
| 0 | [欢迎进入课程](https://huggingface.co/learn/agents-course/en/unit0/introduction) | 欢迎语、使用指南、必备工具及课程概览。 |
| 1 | [Agent 简介](https://huggingface.co/learn/agents-course/en/unit1/introduction) | Agent 定义、大语言模型（LLM）、模型家族树及特殊 Token。 |
| 1 附加单元 | [为函数调用微调大语言模型](https://huggingface.co/learn/agents-course/bonus-unit1/introduction) | 学习如何针对函数调用（Function Calling）对 LLM 进行微调。 |
| 2 | [AI Agent 框架](https://huggingface.co/learn/agents-course/unit2/introduction) | `smolagents`、`LangGraph` 和 `LlamaIndex` 概览。 |
| 2.1 | [Smolagents 框架](https://huggingface.co/learn/agents-course/unit2/smolagents/introduction) | 学习如何使用轻量且强大的 AI Agent 构建库 `smolagents` 来开发高效的智能体。 |
| 2.2 | [LlamaIndex 框架](https://huggingface.co/learn/agents-course/unit2/llama-index/introduction) | 学习如何使用 `LlamaIndex` 工具包，通过索引和工作流基于你的数据构建由大语言模型驱动的 Agent。 |
| 2.3 | [LangGraph 框架](https://huggingface.co/learn/agents-course/unit2/langgraph/introduction) | 学习如何使用 `LangGraph` 框架构建生产级应用，掌握对 Agent 流程的控制工具。 |
| 2 附加单元 | [可观测性与评估](https://huggingface.co/learn/agents-course/bonus-unit2/introduction) | 学习如何追踪和评估你的 Agent。 |
| 3 | [Agentic RAG 应用场景](https://huggingface.co/learn/agents-course/unit3/agentic-rag/introduction) | 学习如何使用 Agentic RAG，借助多种框架帮助 Agent 应对不同的应用场景。 |
| 4 | [最终项目：创建、测试与认证你的 Agent](https://huggingface.co/learn/agents-course/unit4/introduction) | 对 Agent 进行自动化评估，并通过排行榜展示学员成绩。 |
| 3 附加单元 | [宝可梦游戏中的 Agent](https://huggingface.co/learn/agents-course/bonus-unit3/introduction) | 探索 AI Agent 与游戏结合的激动人心的交叉领域。 |

## 前置要求

- 具备 Python 基础
- 了解大语言模型（LLM）基础知识

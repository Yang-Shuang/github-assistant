# 项目创意与资源库 ⚡💙⚡

![head](https://user-images.githubusercontent.com/61475220/97102081-807edc80-16c8-11eb-901c-f7d332efa79c.png)

<img src="https://user-images.githubusercontent.com/61475220/97093903-6d8aee80-166d-11eb-8799-13e119380d2b.jpg" width="50%" align=right>

你是否曾想动手做点什么，却不知从何下手？正如作家有时会遭遇“写作瓶颈”，开发者也常面临同样的困境。这份清单正是为了解决这一问题而生！👍

这些应用项目：
- 非常适合提升你的编程技能 :muscle:；
- 非常适合用来尝试新技术 🆕；
- 非常适合加入你的作品集，以此给未来的雇主/客户留下深刻印象 :file_folder:；
- 非常适合作为教程（文章或视频）的示例 :page_with_curl:；
- 易于完成，且方便后续扩展新功能 :ok_hand:。

这不仅仅是一份简单的项目列表，而是一个详细描述了每个项目的资源库，足以让你从零开始独立开发！

每个项目都包含以下**特性**：

1. 清晰明确的目标描述；
2. 需要实现的 _用户故事（User Stories）_ 列表（这些故事更多是指导方针，而非强制的待办清单。如果你愿意，可以自由添加自己的故事）；
3. 一系列加分功能（Bonus features），不仅能完善基础项目，还能同步提升你的技能（可选，建议在完成必需的用户故事后再尝试）；
4. 所有帮助你完成任务所需的资源和链接。

## Projects 🚀

项目根据完成所需的知识与经验分为三个等级。

| 等级 | 开发者画像                                                                                                                                                |
| :--: | ---------------------------------------------------------------------------------------------------------------------------------------------------------------- |
|  1   | 处于学习初期的开发者。通常专注于开发面向用户的应用程序。                                  |
|  2   | 具备中级学习与经验的开发者。熟悉 UI/UX、开发工具，并能构建使用 API 服务的应用。 |
|  3   | 掌握上述所有技能，并正在学习更高级技术的开发者，如后端应用开发与数据库服务。                    |

## Contribution ❤

非常欢迎任何形式的贡献。:pray: 你可以通过两种方式参与：

1. 提交 Issue 并告诉我们你的想法 :bulb:。请务必使用 `new idea`（新创意）标签；
2. Fork 该项目并提交包含你新创意的 PR。在此之前，请确保已阅读并遵循 [贡献指南](./CONTRIBUTION.md)；

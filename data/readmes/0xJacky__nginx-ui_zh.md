### 功能特性

- 在线统计服务器指标，如 CPU 使用率、内存使用率、系统负载和磁盘使用情况。
- 更改后自动备份配置，支持版本对比与恢复。
- 集群管理，支持将操作镜像到多个节点，轻松管理多服务器环境。
- 导出加密的 Nginx / Nginx UI 配置文件，以便快速部署并恢复到新环境中。
- 增强的在线 **ChatGPT** 助手，支持多种模型，包括 Deepseek-R1 的思维链（Chain-of-Thought）显示，帮助你更好地理解和优化配置。
- **MCP**（模型上下文协议）为 AI Agent 提供专用接口以与 Nginx UI 交互，实现自动化配置管理与服务控制。
- 一键部署并自动续期 Let's Encrypt 证书。
- 在线编辑网站配置：使用我们自研的 **NgxConfigEditor**（一款对 Nginx 配置友好的可视化块编辑器）或 **Ace Code Editor**（支持 **LLM 代码补全**及高亮显示 Nginx 配置语法）。
- 在线查看 Nginx 日志。
- 基于 Go 和 Vue 开发，发布包为单个可执行文件。
- 保存配置后自动测试配置文件并重新加载 Nginx。
- Web 终端（Web Terminal）
- 深色模式（Dark Mode）
- 响应式网页设计

## 快速开始

### 使用前准备

Nginx UI 遵循 Debian Web 服务器配置文件标准。创建的网站配置文件将放置在 Nginx 配置文件夹下的 `sites-available` 目录中（自动检测）。已启用的站点配置将在 `sites-enabled` 目录下创建软链接。你可能需要调整配置文件的组织方式。

对于非 Debian（及 Ubuntu）系统，你可能需要将 `nginx.conf` 配置文件的内容修改为如下 Debian 风格：

```nginx
http {
	# ...
	include /etc/nginx/conf.d/*.conf;
	include /etc/nginx/sites-enabled/*;
}
```

更多信息请参见：[debian/conf/nginx.conf](https://salsa.debian.org/nginx-team/nginx/-/blob/master/debian/conf/nginx.conf#L59-L60)

### 安装

Nginx UI 支持以下平台：

- macOS 11 Big Sur 及更高版本（amd64 / arm64）
- Windows 10 及更高版本（amd64 / arm64）
- Linux 2.6.23 及更高版本（x86 / amd64 / arm64 / armv5 / armv6 / armv7 / mips32 / mips64 / riscv64 / loongarch64）
  - 包括但不限于 Debian 7/8、Ubuntu 12.04/14.04 及更高版本、CentOS 6/7、Arch Linux
- FreeBSD
- OpenBSD
- Dragonfly BSD
- Openwrt

你可以访问 [最新发行版](https://github.com/0xJacky/nginx-ui/releases/latest) 下载最新版本，或直接使用 [Linux 安装脚本](#script-for-linux)。

### 使用方法

首次运行 Nginx UI 时，请在浏览器中访问 `http://<your_server_ip>:<listen_port>` 完成后续配置。

#### 从可执行文件运行
**在终端中运行 Nginx UI**

```shell
nginx-ui -config app.ini
```
按 `Control+C` 退出 Nginx UI。

**后台运行 Nginx UI**

```shell
nohup ./nginx-ui -config app.ini &
```
使用以下命令停止 Nginx UI：

```shell
kill -9 $(ps -aux | grep nginx-ui | grep -v grep | awk '{print $2}')
```

#### 使用 Systemd
如果你使用的是 [Linux 安装脚本](#script-for-linux)，Nginx UI 将作为 `nginx-ui` 服务安装在 systemd 中。请使用 `systemctl` 命令进行控制。

**启动 Nginx UI**

```shell
systemctl start nginx-ui
```
**停止 Nginx UI**

```shell
systemctl stop nginx-ui
```
**重启 Nginx UI**

```shell
systemctl restart nginx-ui
```

#### 使用 Docker
我们的 Docker 镜像 [uozi/nginx-ui:latest](https://hub.docker.com/r/uozi/nginx-ui) 基于最新的 Nginx 镜像构建，可用于替换宿主机上的 Nginx。通过将容器的 `80` 和 `443` 端口映射到宿主机，你可以轻松完成切换。

##### 注意事项
1. 首次使用该容器时，请确保映射到 `/etc/nginx` 的卷目录为空。
2. 如果你想托管静态文件，可以将目录映射到容器中。
3. 如果你是从旧版本镜像升级，请参阅 [Docker WebSocket 修复指南](https://nginxui.com/guide/docker-websocket-fix.html) 以完成 `conf.d/nginx-ui.conf` 的必要更新。

<details>
<summary><b>使用 Docker 部署</b></summary>

1. [安装 Docker。](https://docs.docker.com/install/)

2. 然后按如下方式部署 nginx-ui：

```bash
docker run -dit \
  --name=nginx-ui \
  --restart=always \
  -e TZ=Asia/Shanghai \
  -v /mnt/user/appdata/nginx:/etc/nginx \
  -v /mnt/user/appdata/nginx-ui:/etc/nginx-ui \
  -v /var/run/docker.sock:/var/run/docker.sock \
  -p 8080:80 -p 8443:443 \
  uozi/nginx-ui:latest
```

3. 当你的 Docker 容器运行时，通过 `http://<your_server_ip>:8080/install` 登录 Nginx UI 面板。如果修改了端口映射，请改为访问映射到容器 `80` 端口的宿主机端口。
</details>

<details>
<summary><b>使用 Docker-Compose 部署</b></summary>

1. [安装 Docker-Compose。](https://docs.docker.com/compose/install/)

2. 创建如下内容的 docker-compose.yml 文件：

```yml
services:
    nginx-ui:
        stdin_open: true
        tty: true
        container_name: nginx-ui
        restart: always
        environment:
            - TZ=Asia/Shanghai
        volumes:
            - '/mnt/user/appdata/nginx:/etc/nginx'
            - '/mnt/user/appdata/nginx-ui:/etc/nginx-ui'
            - '/var/www:/var/www'
            - '/var/run/docker.sock:/var/run/docker.sock'
        ports:
            - 8080:80
            - 8443:443
        image: 'uozi/nginx-ui:latest'
```

3. 然后创建你的容器：
```bash
docker compose up -d
```

4. 当你的 Docker 容器运行时，通过 `http://<your_server_ip>:8080/install` 登录 Nginx UI 面板。如果修改了端口映射，请改为访问映射到容器 `80` 端口的宿主机端口。

</details>

## 手动构建

在没有官方构建版本的平台，可以手动进行编译。

### 前置条件

- Make

- Golang 1.23+

- node.js 21+

  ```shell
  npx browserslist@latest --update-db
  ```

### 构建前端

请在 `app` 目录下执行以下命令：

```shell
pnpm install
pnpm build
```

### 构建后端

请先完成应用编译，然后在项目根目录下执行以下命令：

```shell
go generate
go build -tags=jsoniter -ldflags "$LD_FLAGS -X 'github.com/0xJacky/Nginx-UI/settings/buildTime=$(date +%s)'" -o nginx-ui -v main.go
```

## Linux 脚本

### 基本用法

**安装与升级**

```shell
bash -c "$(curl -L https://cloud.nginxui.com/install.sh)" @ install
```
默认监听端口为 `9000`，默认的 HTTP Challenge 端口为 `9180`。如果存在端口冲突，请手动修改 `/usr/local/etc/nginx-ui/app.ini`，然后使用 `systemctl restart nginx-ui` 重新加载 Nginx UI 服务。

**卸载 Nginx UI（保留配置文件和数据库文件）**

```shell
bash -c "$(curl -L https://cloud.nginxui.com/install.sh)" @ remove
```

### 更多用法

````shell
bash -c "$(curl -L https://cloud.nginxui.com/install.sh)" @ help
````

## Nginx 反向代理配置示例

```nginx
server {
    listen          80;
    listen          [::]:80;

    server_name     <your_server_name>;
    rewrite ^(.*)$  https://$host$1 permanent;
}

map $http_upgrade $connection_upgrade {
    default upgrade;
    ''      close;
}

server {
    listen  443       ssl;
    listen  [::]:443  ssl;
    http2   on;

    server_name         <your_server_name>;

    ssl_certificate     /path/to/ssl_cert;
    ssl_certificate_key /path/to/ssl_cert_key;

    location / {
        proxy_set_header    Host                $host;
        proxy_set_header    X-Real-IP           $remote_addr;
        proxy_set_header    X-Forwarded-For     $proxy_add_x_forwarded_for;
        proxy_set_header    X-Forwarded-Proto   $scheme;
        proxy_http_version  1.1;
        proxy_set_header    Upgrade             $http_upgrade;
        proxy_set_header    Connection          $connection_upgrade;
        proxy_pass          http://127.0.0.1:9000/;
    }
}
```

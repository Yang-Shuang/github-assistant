## 🔭 什么是 Astron Agent
Astron Agent 是一个**企业级、对商业友好**的 Agentic Workflow（智能体工作流）开发平台，集成了 AI 工作流编排、模型管理、AI 与 MCP 工具集成、RPA 自动化以及团队协作功能。该平台支持**高可用**部署，使组织能够快速构建**可扩展、面向生产环境**的智能体应用，并为未来奠定 AI 基础。

### 为什么选择 Astron Agent？
- **稳定可靠**：基于科大讯飞 Astron Agent 平台的核心技术构建，提供企业级可靠性，且完全可用的高可用版本已开源。
- **跨系统整合**：原生集成智能 RPA（机器人流程自动化），高效连接企业内部与外部系统，实现智能体与企业系统的无缝交互。
- **企业级开放生态**：深度兼容各类行业模型与工具，支持自定义扩展，灵活适配多样化的企业场景。
- **商业友好**：采用 Apache 2.0 许可证发布，无商业化限制，允许免费商用。

### 核心特性
- **企业级高可用**：覆盖开发、构建、优化与管理的全栈能力，支持一键部署，可靠性强。  
- **智能 RPA 集成**：实现跨系统流程自动化，赋予智能体可控的执行能力，达成“从决策到行动”的完整闭环。  
- **开箱即用的工具生态**：整合了[讯飞开放平台](https://www.xfyun.cn)的海量 AI 能力与工具（经数百万开发者验证），支持即插即用集成，无需额外开发。  
- **灵活的模型接入**：提供多样化的访问方式，从基于 API 的快速模型接入与验证，到企业级 MaaS（模型即服务）本地集群的一键部署，全面满足不同规模的需求。

## 🚀 快速开始

我们提供两种部署方式以满足不同场景需求：

### 方案一：Docker Compose（推荐用于快速开始）

```bash
# Clone the repository
git clone https://github.com/iflytek/astron-agent.git

# Navigate to the Docker deployment directory
cd docker/astronAgent

# Copy environment configuration
cp .env.example .env

# Configure environment variables
vim .env
```

环境变量配置请参考文档：[DEPLOYMENT_GUIDE_WITH_AUTH.md](https://github.com/iflytek/astron-agent/blob/main/docs/DEPLOYMENT_GUIDE_WITH_AUTH.md#step-2-configure-astronagent-environment-variables)

```bash
# Start all services (including Casdoor)
docker compose -f docker-compose-with-auth.yaml up -d
```

#### 📊 服务访问地址

启动后，你可以通过以下地址访问各项服务：

**认证服务**
- **Casdoor Admin Interface**: http://localhost:8000

**Astron Agent**
- **Application Frontend (nginx proxy)**: http://localhost/

**注意事项**
- 默认 Casdoor 登录凭据：用户名 `admin`，密码 `123`

### 方案二：Helm（适用于 Kubernetes 环境）

> 🚧 **注意**：目前 Helm Chart 正在开发中，敬请期待更新！

```bash
# Coming soon
# helm repo add astron-agent https://iflytek.github.io/astron-agent
# helm install astron-agent astron-agent/astron-agent
```

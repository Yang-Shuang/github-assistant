# Model Context Protocol (MCP)

刚接触 MCP，不知道从何入手？请查看我们的[文档网站](https://modelcontextprotocol.io)。

本仓库包含以下内容：

- MCP 规范
- MCP 协议 Schema
- 官方 MCP 文档

该模式（Schema）首先以 [TypeScript 定义](schema/2025-11-25/schema.ts) 编写，同时为了提供更广泛的兼容性，也提供了 [JSON Schema 格式版本](schema/2025-11-25/schema.json)。

官方 MCP 文档基于 Mintlify 构建，可访问[modelcontextprotocol.io](https://modelcontextprotocol.io)。

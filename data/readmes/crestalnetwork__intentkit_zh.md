IntentKit 是一个开源、支持自托管的云智能体集群，为你管理一支协同工作的 AI Agent 团队。

## 为什么选择 IntentKit

目前的 AI 智能体通常遵循两条路径：

1. **本地优先（Local-First）**（例如 OpenClaw）：这类工具主要作为个人助手或实验性项目使用。但它们通常需要昂贵的硬件支持，并且需要授予广泛的本地权限。
2. **云原生（Cloud-Native）**：类似于现代 Web 应用，它们运行在云端，几乎不消耗本地资源，无需维护，并能高可靠地完成各类任务。

如果你正在寻找一个稳定可靠的云原生解决方案，IntentKit 正是为你打造的。

## 功能特性

- ☁️ **云原生架构：** 极致优化资源使用。
- 🔒 **安全设计：** 智能体从根本上无法访问你的任何密钥（secret keys）。
- 🤖 **协同 AI：** 支持多个智能体相互调用与交互。
- 🔄 **开箱即用：** 预置完整配置，安装即可直接使用。
- 🔗 **兼容加密技术：** 可选的 Web3 和区块链集成支持。
- 🐦 **社交媒体整合：** 无缝对接各类社交平台。
- 🛠️ **可扩展技能系统：** 轻松添加新功能与能力。

## 其他使用场景

除了自托管部署 IntentKit，你还可以通过以下方式使用该开源项目：

- **作为 Python 库：** 导入并扩展 IntentKit，或将其集成到你现有的项目中，为其添加智能体集群能力。
- **通过 API 调用：** 无论采用何种部署方式，你都可以通过内置的 API 端点从外部应用与智能体进行交互。

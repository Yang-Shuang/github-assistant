### 产品概述

AnythingLLM 是一款一体化 AI 应用，让你能够构建一个私有的、功能完整的 ChatGPT——无需妥协。连接你偏好的本地或云端 LLM，导入你的文档，几分钟内即可开始对话。开箱即用，内置 Agent（智能体）、多用户支持、向量数据库和文档处理管道——无需额外配置。

AnythingLLM 同样支持多用户环境，你可以为每个用户精细控制访问权限与使用体验，同时完全保障实例的安全性、隐私性以及你的知识产权不受损。

## AnythingLLM 的亮点功能

- [动态模型路由](https://docs.anythingllm.com/model-router/overview) - 根据你定义的规则，自动将对话路由到最佳提供商和模型。
- [自动与用户管理记忆](https://docs.anythingllm.com/features/memories) - 让 LLM 记住关于你或工作区的重要信息。
- [定时任务](https://docs.anythingllm.com/scheduled-jobs/overview) - 以 Cron 计划任务的方式运行周期性任务或提示词，并具备完整的 Agent（智能体）能力。
- [智能技能选择](https://docs.anythingllm.com/agent/intelligent-tool-selection) Enable **unlimited** tools for your models while reducing token usage by up to 80% per query -> 为你的模型启用**无限**数量的工具，同时将每次查询的 Token 消耗降低高达 80%。
- [无代码 AI Agent（智能体）构建器](https://docs.anythingllm.com/agent-flows/overview)
- [MCP 兼容性](https://docs.anythingllm.com/mcp-compatibility/overview)
- [多模态支持（涵盖闭源和开源 LLM！）](https://docs.anythingllm.com/features/multimodal)
- [自定义 AI Agent（智能体）](https://docs.anythingllm.com/agent/custom/introduction)
- 👤 多用户实例支持与权限管理 _仅限 Docker 版本_
- 🦾 工作区内的 Agent（智能体）（支持网页浏览等）

- 📖 多种文档类型支持（PDF、TXT、DOCX 等）

### 技术架构概览

该 Monorepo（单体仓库）包含六个主要部分：

- `frontend`: A viteJS + React frontend that you can run to easily create and manage all your content the LLM can use. -> **`frontend`**：基于 ViteJS + React 的前端，让你能够轻松创建和管理 LLM 使用的所有内容。
- `server`: A NodeJS express server to handle all the interactions and do all the vectorDB management and LLM interactions. -> **`server`**：基于 Node.js Express 的后端服务器，负责处理所有交互、向量数据库管理以及与 LLM 的通信。
- `collector`: NodeJS express server that processes and parses documents from the UI. -> **`collector`**：Node.js Express 服务器，用于处理和解析来自 UI 的文档。
- `docker`: Docker instructions and build process + information for building from source. -> **`docker`**：Docker 构建说明、流程及源码编译指南。
- `embed`: Submodule for generation & creation of the [web embed widget](https://github.com/Mintplex-Labs/anythingllm-embed). -> **`embed`**：[网页嵌入组件](...) 的生成与创建子模块。
- `browser-extension`: Submodule for the [chrome browser extension](https://github.com/Mintplex-Labs/anythingllm-extension). -> **`browser-extension`**：[Chrome 浏览器扩展](...) 的子模块。

## 开发环境配置

- `yarn setup` To fill in the required `.env` files you'll need in each of the application sections (from root of repo).
  - Go fill those out before proceeding. Ensure `server/.env.development` is filled or else things won't work right. -> - `yarn setup`：用于填写应用各部分所需的 `.env` 文件（从仓库根目录执行）。
    - 请在继续操作前完成填写。确保 `server/.env.development` 已正确配置，否则功能将无法正常运行。
- `yarn dev:server` To boot the server locally (from root of repo). -> - `yarn dev:server`：在本地启动后端服务（从仓库根目录执行）。
- `yarn dev:frontend` To boot the frontend locally (from root of repo). -> - `yarn dev:frontend`：在本地启动前端界面（从仓库根目录执行）。
- `yarn dev:collector` To then run the document collector (from root of repo). -> - `yarn dev:collector`：随后运行文档收集器服务（从仓库根目录执行）。

## 遥测数据与隐私政策

Mintplex Labs Inc 出品的 AnythingLLM 包含一项遥测（Telemetry）功能，用于收集匿名使用信息。

<details>
<summary><kbd>关于 AnythingLLM 的遥测数据与隐私详情</kbd></summary>

### 为什么需要？

我们利用这些信息了解 AnythingLLM 的使用情况，以便优先开发新功能、修复 Bug，并提升产品的性能与稳定性。

### 如何退出（关闭）？

在服务器或 Docker 的 `.env` 配置中将 `DISABLE_TELEMETRY` 设置为 `"true"` 即可退出遥测。你也可以在应用内通过侧边栏 > `Privacy（隐私）` 选项关闭它。

### 具体会追踪哪些数据？

我们仅收集有助于产品与路线图决策的使用详情，具体如下：

- Type of your installation (Docker or Desktop) -> - 你的安装类型（Docker 或桌面版）
- When a document is added or removed. No information _about_ the document. Just that the event occurred. This gives us an idea of use. -> - 文档添加或删除的时间。不收集任何关于文档的_内容信息_，仅记录事件发生。这能帮助我们了解使用频率。
- Type of vector database in use. This helps us prioritize changes when updates arrive for that provider. -> - 使用的向量数据库类型。当该提供商发布更新时，有助于我们优先进行适配调整。
- Type of LLM provider & model tag in use. This helps us prioritize changes when updates arrive for that provider or model, or combination thereof. eg: reasoning vs regular, multi-modal models, etc. -> - 使用的 LLM 提供商及模型标签。当该提供商或模型发布更新（如推理型与普通型、多模态模型等）时，有助于我们优先进行适配调整。
- When a chat is sent. This is the most regular "event" and gives us an idea of the daily-activity of this project across all installations. Again, only the **event** is sent - we have no information on the nature or content of the chat itself. -> - 对话发送时间。这是最频繁的“事件”，能帮助我们了解该项目在所有安装实例中的日常活跃度。再次强调，仅发送**事件标记**——我们完全无法获知聊天本身的性质或内容。

You can verify these claims by finding all locations `Telemetry.sendTelemetry` is called. Additionally these events are written to the output log so you can also see the specific data which was sent - if enabled. **No IP or other identifying information is collected**. The Telemetry provider is [PostHog](https://posthog.com/) - an open-source telemetry collection service. -> 你可以通过搜索代码中所有调用 `Telemetry.sendTelemetry` 的位置来验证上述声明。此外，这些事件会写入输出日志，启用后你也可以查看具体发送的数据。**不会收集任何 IP 或其他身份信息**。遥测服务由 [PostHog](https://posthog.com/)（一款开源的遥测数据收集服务）提供。

We take privacy very seriously, and we hope you understand that we want to learn how our tool is used, without using annoying popup surveys, so we can build something worth using. The anonymous data is _never_ shared with third parties, ever. -> 我们高度重视隐私问题，希望你能理解：我们希望在不使用烦人弹窗调查的前提下了解工具的使用方式，从而打造出真正值得使用的产品。匿名数据_绝不会_与任何第三方共享。

[View all telemetry events in source code](https://github.com/search?q=repo%3AMintplex-Labs%2Fanything-llm%20.sendTelemetry(&type=code) -> [在源代码中查看所有遥测事件](...)

### 其他出站连接

If you disable telemetry, you would still see outbound connections to the following services: -> 即使你禁用了遥测，仍可能会看到以下服务的出站连接：
- If using an external tool, LLM, Embedding models, or Vector databases, you will still see outbound connections to the respective service provider. -> - 如果你使用了外部工具、LLM、Embedder（嵌入）模型或向量数据库，仍会向相应的服务提供商发起出站连接。
- `cdn.anythingllm.com` for pulling models from our mirror CDN. This is not tracked by telemetry and is actually useful for those in VPN restricted regions. -> - `cdn.anythingllm.com` 用于从我们的镜像 CDN 拉取模型。这不属于遥测追踪范围，对处于网络受限地区的用户反而很有帮助。
- `github/githubusercontent.com` There are some various flat files that are downloaded from these domains for context window caching. -> - `github/githubusercontent.com`：部分静态文件会从这些域名下载，用于上下文窗口缓存。

Basically, if telemetry is disabled we don't collect anything. However, depending on your setup you may still see outbound connections and would be subject to the terms of service of the respective service provider. -> 简而言之，如果禁用遥测，我们不会收集任何数据。但根据你的具体部署环境，仍可能看到出站连接，这些连接将受相应服务提供商的服务条款约束。

## Roo Code 能为你做什么？

- 根据自然语言描述和需求生成代码
- 支持多种模式：Code、Architect、Ask、Debug 及自定义模式
- 重构与调试现有代码
- 编写与更新文档
- 解答关于你代码库的问题
- 自动化重复性任务
- 利用 MCP Server

## 模式

Roo Code 适应你的工作方式：

- Code（编码）模式：日常编码、代码编辑与文件操作
- Architect（架构）模式：规划系统、编写规范文档及进行迁移
- Ask（问答）模式：快速获取答案、解释说明与生成文档
- Debug（调试）模式：追踪问题、添加日志并定位根本原因
- 自定义模式：为你的团队或工作流构建专用模式

了解更多：[使用模式](https://roocodeinc.github.io/Roo-Code/basic-usage/using-modes) • [自定义模式](https://roocodeinc.github.io/Roo-Code/advanced-usage/custom-modes)

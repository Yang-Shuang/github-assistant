goose 是一款运行在你本地设备上的通用型 AI 智能体。它不仅限于代码开发，还可用于研究、写作、自动化处理、数据分析或任何你需要完成的任务。

提供适用于 macOS、Linux 和 Windows 的原生桌面应用。配备完整的终端命令行工具（CLI）以支持工作流操作。提供 API 以便将其嵌入任意平台。项目采用 Rust 语言开发，兼顾高性能与跨平台移植性。

goose 兼容 15 多家模型提供商（包括 Anthropic、OpenAI、Google、Ollama、OpenRouter、Azure、Bedrock 等）。你可以通过 API 密钥，或借助 [ACP](https://goose-docs.ai/docs/guides/acp-providers) 直接使用现有的 Claude、ChatGPT 或 Gemini 订阅。通过开源标准 [Model Context Protocol (MCP)](https://modelcontextprotocol.io/)，可连接 70 多种扩展插件。

goose 是 Linux 基金会旗下 [Agentic AI Foundation (AAIF)](https://aaif.io/) 的一部分。

# 快速入门
**[下载桌面应用](https://goose-docs.ai/docs/getting-started/installation)**（支持 macOS、Linux 和 Windows）。

或通过命令行安装 CLI：

```bash
curl -fsSL https://github.com/aaif-goose/goose/releases/download/stable/download_cli.sh | bash
```

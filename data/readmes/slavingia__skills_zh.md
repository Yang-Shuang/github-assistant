# 《极简创业者》—— Claude Code 技能

基于 Sahil Lavingia 所著《极简创业者》（[官网链接](https://www.minimalistentrepreneur.com/)）的 Claude Code 技能。

## 安装

在 Claude Code 中：

```
/plugin marketplace add slavingia/skills
/plugin install minimalist-entrepreneur
```

完成以上步骤即可——Claude Code 将自动拉取仓库并注册全部 10 项技能。

<details>
<summary>替代方案：从本地克隆版本安装</summary>

```bash
git clone https://github.com/slavingia/skills.git ~/.claude/plugins/skills
```

然后在 Claude Code 中：

```
/plugin marketplace add ~/.claude/plugins/skills
/plugin install minimalist-entrepreneur
```

</details>

## 技能列表

| 技能名称 | 命令 | 适用场景 |
|-------|---------|-------------|
| **寻找社区** | `/find-community` | 正在构思商业点子，或试图找到你的目标受众时 |
| **验证想法** | `/validate-idea` | 测试某个商业点子是否值得投入开发时 |
| **最小可行产品（MVP）** | `/mvp` | 准备构建首款产品，但难以把控项目范围时 |
| **流程化** | `/processize` | 已有产品创意，希望在写代码前通过手工方式交付价值时 |
| **获取首批客户** | `/first-customers` | 拥有产品后，需要找到你的前 100 位客户时 |
| **定价策略** | `/pricing` | 制定价格或考虑调整价格时 |
| **营销计划** | `/marketing-plan` | 已实现产品市场契合度（product-market fit），准备通过内容扩大规模时 |
| **可持续增长** | `/grow-sustainably` | 在支出、招聘或扩张等决策上需要指导时 |
| **公司价值观** | `/company-values` | 定义企业文化，为招聘做准备时 |
| **极简审查** | `/minimalist-review` | 对任何商业决策进行直觉与原则校验时 |

## 《极简创业者》成长路径

这些技能严格遵循书中的演进阶段：

1. **社区（Community）** —— 从寻找你的同路人开始
2. **验证（Validate）** —— 确保该问题值得解决
3. **构建（Build）** —— 先交付手工流程，再将其产品化
4. **流程化（Processize）** —— 将你的产品创意转化为今天即可执行的手工流程
5. **销售（Sell）** —— 逐一获取 100 位客户
6. **定价（Price）** —— 从第一天起就收取费用
7. **营销（Market）** —— 通过内容积累受众
8. **增长（Grow）** —— 保持盈利，实现可持续增长
9. **文化（Culture）** —— 打造你愿意长期栖居的企业家园
10. **审查（Review）** —— 将极简原则应用于每一项决策

## MINDS PLATFORM 

Minds Platform 致力于构建面向前沿人工智能的开放基础架构，专为寻求可真正掌控、扩展并部署于任何环境（VPC、本地或云端）AI 系统的开发者、企业及个人而设计。

我们认为，实用的 AI 系统必须具备两项核心能力：自主执行有意义操作的能力**（自动化 Automation）**与查找并检索准确信息的能力**（语义搜索 Semantic Search）**。我们的产品均围绕这两大基础构建： 

* [Minds Anton](https://github.com/mindsdb/anton) - 具备自我进化能力的**Automation**智能体，可处理各类任务。只需用自然语言告知它你的需求，它将自动完成后续工作——生成报表、整理数据、发送邮件、调用 API、构建仪表盘、安排任务等。 

* [Minds Query Engine](https://github.com/mindsdb/engine) - **Semantic Search**查询引擎，用于对来自数百个结构化与非结构化数据源的庞大数据进行索引与组织。


# 典型应用场景

| 应用场景 | 解决方案 |
|---|---|
| 自动化报表、周期性工作流与日常任务执行 | **Anton** |
| 可嵌入的对话式商业智能 (BI) | **Query Engine** |
| 跨大型知识库（文档、工单等）进行搜索 | **Query Engine** |
| 搜索与分析大型知识库中的数据（文档、工单等） | **Anton + Query Engine** |
| 面向销售、客服、财务及工程团队的 AI 运营助手 | **Anton** |
| 融合记忆、检索、推理与执行能力的大规模企业级 AI 系统 | **Anton + Query Engine** |

# 随处部署

Minds Platform 支持在以下环境中灵活部署：

- 云端 (Cloud)
- VPC
- 本地部署 (On-Prem)
- 物理隔离环境 (Air-Gapped Environments)
- 混合基础设施 (Hybrid Infrastructure)

你可完全掌控你的基础设施、模型、权限（permission）与数据。

## 什么是 Open Design

🎨 **本地优先的开源 [Claude Design][cd] 替代品。** &nbsp;🖥️ **macOS 和 Windows 原生桌面应用。** &nbsp;⚡ **100+ 技能** · ✨ **150 套品牌级 `DESIGN.md` 系统** · 📦 **261 款开箱即用的插件。** &nbsp;🖼️ 生成 **网页 · 桌面 · 移动端原型**、**实时仪表盘 / 动态组件**、**演示文稿**、**图片**、**视频**，以及 **HyperFrames** 动效。 🔒 沙盒 iframe 预览 · HTML / PDF / PPTX / MP4 导出。 &nbsp;🤖 **支持 Claude Code · OpenClaw · Codex · Cursor · OpenCode · Qwen · Copilot · Hermes · Kimi · Antigravity 及 21 款本地 CLI**，或通过 BYOK（自带密钥）接入任何兼容 OpenAI 的端点。

当你将 Anthropic 随 Claude Design 推出的 **Agent 原生工作流** ——发现需求、锁定方向、流式生成产物、评审交付——从封闭系统转变为开放生态时，Open Design 就诞生了。它变成了一个由技能、设计系统和插件组成的文件系统，你电脑上的编码 Agent 可以直接读取、编写和重组这些内容。你的 CLI 成为设计引擎，你的笔记本成为工作室，而你团队的 `DESIGN.md` 则成为品牌契约。

它也是 **Agent 时代的 Figma 替代品**——不再是在画布上拖拽像素，而是直接交付使用真实 CSS、真实字体和真实组件的单页动态组件，并一键导出为 HTML / PDF / PPTX / MP4。这些内容已内置你的设计系统规范，且可直接在你每天使用的 Agent 中运行。

[cd]: https://x.com/claudeai/status/2045156267690213649

## 平台兼容性

> Open Design 以 **技能、CLI 和 MCP 服务器** 的形式分发，主流编码 Agent 可原生调用。安装 OD 后，只需一条命令 `od mcp install <agent>` 即可将 MCP 服务器接入该 Agent 的配置中，随后你便可在任何 Agent 内部直接调用相同的工具。

| Coding agent / platform &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; | Status &nbsp;&nbsp; | One-line MCP server install &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; |
|---|:---:|---|
| [Claude Code](https://docs.anthropic.com/en/docs/claude-code) | ✅ Supported | `od mcp install claude` |
| [Codex CLI](https://github.com/openai/codex) | ✅ Supported | `od mcp install codex` |
| [Cursor](https://www.cursor.com/cli) | ✅ Supported | `od mcp install cursor` |
| [VS Code + GitHub Copilot](https://github.com/features/copilot) | ✅ Supported | `od mcp install copilot` |
| [GitHub Copilot CLI](https://github.com/features/copilot/cli) | ✅ Supported | `od mcp install copilot` |
| Gemini CLI | ✅ Supported | `od mcp install gemini` |
| [OpenCode](https://opencode.ai/) | ✅ Supported | `od mcp install opencode` |
| [OpenClaw](https://github.com/openclaw/openclaw) | ✅ Supported | `od mcp install openclaw` |
| [Antigravity](https://antigravity.google) | ✅ Supported | `od mcp install antigravity` |
| [Cline](https://github.com/cline/cline) | ✅ Supported | `od mcp install cline` |
| [Trae](https://www.trae.ai/) | ✅ Supported | `od mcp install trae` |
| Kimi CLI | ✅ Supported | `od mcp install kimi` |

**未安装 CLI？** 通过 BYOK 代理 `POST /api/proxy/{anthropic,openai,azure,google,ollama,senseaudio}/stream`，你也能获得相同的工作流（无需启动进程）——只需粘贴 `baseUrl` + `apiKey` + `model`，即支持 OpenAI、Anthropic、Azure OpenAI、Google Gemini、Ollama、LM Studio、vLLM 或任何兼容 OpenAI 的端点。守护进程在边缘层针对每个目标提供 SSRF 防护，拦截内网 IP / 链接本地地址 / CGNAT。

适配器契约与流解析器位于 [`apps/daemon/src/agents.ts`](apps/daemon/src/agents.ts)。添加新 CLI 仅需一行配置——详见 [`docs/agent-adapters.md`](docs/agent-adapters.md)。

## 为什么选择 Open Design

> **2026年4月，Anthropic 发布了 [Claude Design][cd]——这是 LLM 首次停止撰写长文，转而直接交付设计产物。** 它迅速走红。但它始终闭源、仅限付费、仅支持云端、绑定 Anthropic 的模型与技能及交互界面。无法本地部署、无法自托管、无法一键部署至 Vercel、也无法替换为你自己的 Agent。

Open Design (OD) 是它的开源替代品。相同的工作流，相同的产物优先心智模型，但没有任何锁定效应：

- 🤖 **Agent 原生，模型无关。** 我们不捆绑 Agent。你 `PATH` 环境变量中已有的 `claude` / `codex` / `cursor-agent` / `copilot` / `hermes` / `kimi` 就是设计引擎。一键切换。
- 🧠 **默认品牌级规范。** 每次渲染都会读取当前的 `DESIGN.md`——涵盖色板、字体、间距、动效、语调、反模式等 9 个部分的架构。仓库内置 150 套系统（Linear, Stripe, Vercel, Airbnb, Apple, Tesla, Notion, Anthropic, Cursor, Supabase, Figma…）。放入文件夹，选择器即可自动识别。
- 🖥️ **本地优先，全链路 BYOK。** macOS (Apple Silicon + Intel) 和 Windows (x64) 原生桌面应用。Linux AppImage 在可选发布通道中提供。SQLite 存储于 `.od/app.sqlite`，文件位于 `.od/projects/<id>/`，无遥测数据，无云端往返请求。
- 🌍 **三层可组合架构。** **插件**承载可执行工作流 · **技能**承载 Agent 的设计品味 · **设计系统**承载品牌规范。三者均为纯文本文件，任何人皆可编写、版本控制和发布。
- 🔁 **刷新现有代码库。** 将 `git` 仓库 + `DESIGN.md` 交给 Agent，它会将你的真实组件重构为符合品牌规范的代码。专用插件可将 Figma / Pencil 工作流迁移至 React / Next.js / Vue 代码中。
- 🔒 **隐私为本。** 所有数据均在本地运行——你的笔记本、团队服务器或 Vercel 项目。当需要网络时，BYOK 代理提供 SSRF 防护。

## 快速开始

### 🖥️ 下载桌面应用（推荐 —— 零配置）

使用 Open Design 最快的方式。无需 Node，无需 pnpm，无需 clone。

- **macOS** (Apple Silicon · Intel x64) → [**open-design.ai**](https://open-design.ai/) 或 [GitHub Releases](https://github.com/nexu-io/open-design/releases)
- **Windows** (x64) → [**open-design.ai**](https://open-design.ai/) 或 [GitHub Releases](https://github.com/nexu-io/open-design/releases)
- **Linux** (AppImage, optional lane) → [GitHub Releases](https://github.com/nexu-io/open-design/releases)

安装后：应用会自动检测你 `PATH` 中的所有编码 Agent CLI，加载 100+ 技能和 150 套设计系统，并允许你在入口视图中输入需求说明。

### 🤖 安装至你的编码 Agent（无需 GUI）

你可以完全不开启图形界面使用 Open Design——将其作为技能、插件或 MCP 服务器调用，适用于 Claude Code、Codex、Cursor、Copilot、OpenClaw、Antigravity、Hermes、Kimi 等。

```bash
# One-line install into the agent you're using:
curl -fsSL https://open-design.ai/install.sh | sh -s <agent>
# <agent> = claude | codex | cursor | copilot | openclaw | antigravity | gemini
#         | pi | vibe | hermes | cline | kimi | trae | opencode
```

随后，在 Agent 内部执行：

```
> Use open-design to generate a landing page with the Linear design system
```

Agent 会读取 `skills/`，选择正确的 `SKILL.md`，绑定你指定的 `DESIGN.md`，并生成 `<artifact>`。预览地址为 `http://localhost:7456`。

### 🐳 使用 Docker 运行

```bash
git clone https://github.com/nexu-io/open-design.git
cd open-design/deploy
cp .env.example .env
echo "OD_API_TOKEN=$(openssl rand -hex 32)" >> .env
docker compose up -d
# open http://localhost:7456
```

### 🧑‍💻 从源码运行

```bash
git clone https://github.com/nexu-io/open-design.git
cd open-design
corepack enable && pnpm install
pnpm tools-dev run web
```

Node `~24`, pnpm `10.33.x`。Windows 用户请参阅 [`docs/windows-troubleshooting.md`](docs/windows-troubleshooting.md)。完整快速入门、环境变量、Nix flake 及打包构建流程 → [`QUICKSTART.md`](QUICKSTART.md)。

### 完整工作流 —— 从需求说明到产物

`brief → plugin → direction → design system → artifact → handoff → memory`

1. **产品经理提交需求说明。** 插件选择器提供落地页 · 演示文稿 · 仪表盘 · 社交媒体帖子 · PM 规范 · OKR 评分表等选项。
2. **设计师（或 Agent）锁定方向。** 没有品牌？从 5 个精选方向中选择。已有品牌？上传截图 / URL → Agent 连接 GitHub、导入 Figma，并生成可复用的 `DESIGN.md`。
3. **Agent 生成首个 `<artifact>`。** 插件 + 技能 + `DESIGN.md` 已绑定。产物流式渲染至沙盒 iframe，支持就地编辑——而非“从头重新生成”。
4. **移交工程团队。** 该产物是真实的 HTML/CSS——直接放入 Cursor、Codex 或 Claude Code 继续以代码形式开发。或直接导出 PPTX / PDF / MP4 交付市场部门。
5. **Open Design 会随你的使用越来越智能。** 你的截图、字体、色板和确认过的产物将作为默认配置累积，供下次会话使用。减少返工，减少偏差。

## 在编码 Agent 中使用 Open Design

Open Design 提供 **stdio MCP 服务器**和 per-agent **安装脚本**。其他仓库中的任何 MCP 兼容 Agent 均可直接读取你本地 Open Design 项目中的文件——tokens CSS、JSX 组件、入口 HTML——作为按名称查询的结构化 API。Agent 始终看到的是实时文件，而非过期导出。

```bash
# One-line install (16+ CLIs supported):
curl -fsSL https://open-design.ai/install.sh | sh -s <agent>

# Then the agent can:
od search-files "primary button"      # search files across projects
od get-file design-systems/linear-app/DESIGN.md
od get-artifact <slug>                # latest rendered artifact
od plugin run web-prototype --brief "..."
od skill list --scenario marketing
```

**为何使用 MCP？** 每次迭代都导出并重新挂载 ZIP 包会打断工作流。MCP 直接暴露设计源码——Agent 始终看到的是实时文件。

**对于从零开始的 Agent，** 安装程序会生成 `~/.config/<agent>/open-design.json`（或平台等效文件）及一段可复制粘贴的 MCP 配置片段。Cursor 提供一键深度链接；Claude Code 提供 `claude mcp add-json` 单行命令；其他所有 Agent 则接收其配置文件所需的 JSON 格式。完整各 Agent 流程 → 桌面应用中的 **设置 (Settings) → MCP 服务器**，或 [`docs/agent-adapters.md`](docs/agent-adapters.md)。

**安全模型。** 默认只读，守护进程绑定至 `127.0.0.1`，SSRF 在代理边缘拦截。局域网暴露需显式配置 `OD_BIND_HOST` 及 `OD_ALLOWED_ORIGINS`。连接器凭证与实时产物预览路由始终仅限本地回环访问。

### 使用插件

插件在 **Web UI** 和 **`od` CLI** 中功能完全对等——共享相同的 `/api/plugins` 端点，按需选择即可。

**在桌面 / Web 应用中：** 打开 **插件 (Plugin)** 页面浏览市场并点击 **安装**；在项目 Studio 内，插件会作为编辑器芯片显示，点击即可应用（附带其声明的输入项）。

**命令行中**（无 UI 运行——这是外部 Agent 使用的路径）：

```bash
od plugin list                       # list installed plugins (--task-kind / --mode / --tag filters)
od plugin search "landing page"      # search by keyword
od plugin info od-default            # inspect a plugin's metadata, inputs, capabilities
od plugin install od-figma-migration # install from a registry; also accepts ./local-folder or an https://… link
od plugin apply od-default --input brief="a one-page pitch for our seed round"
od plugin upgrade od-default         # upgrade
od plugin uninstall od-default       # uninstall
```

所有命令均支持 `--json` 参数，以便通过 `jq` / `xargs` 接入自动化流程。

### 开发插件

一个插件 **最少只需包含 `SKILL.md`**；若要在 Open Design 市场中列出，请添加 `open-design.json`：

```
my-plugin/
├── SKILL.md            ← required: YAML frontmatter (name · description) + trigger phrasing + workflow (aim for < 500 lines)
├── open-design.json    ← needed to list: marketplace metadata + inputs + pipeline + capabilities
├── README.md           ← optional: usage, install, registry links
├── preview/            ← optional: index.html / poster.png (strongly recommended for visual plugins)
└── examples/           ← optional: concrete use cases
```

核心 `open-design.json` 字段：`specVersion`（当前为 `1.0.0`）、`name`（稳定 ID）、`version`（semver）、`compat.agentSkills[].path`（指向 `./SKILL.md`）、`od.kind`（`skill` / `scenario` / `atom` / `bundle`）、`od.taskKind`（`new-generation` / `figma-migration` / `code-migration` / `tune-collab`）、`od.mode`（输出形式，如 `prototype` / `deck` / `live-artifact` / `image` / `video` / `hyperframes` / `audio` / `design-system` / `scenario`）、`od.capabilities[]`（**声明最低要求**——受限安装默认仅授予 `prompt:inject`）、`od.inputs[]`（应用时参数）。

本地生成骨架并验证：

```bash
od plugin scaffold --id my-plugin --title "My Plugin"   # generate the skeleton
od plugin validate ./my-plugin                          # check manifest / file layout
pnpm guard && pnpm --filter @open-design/plugin-runtime typecheck
```

完整字段集与运行时契约 → [`plugins/spec/SPEC.md`](plugins/spec/SPEC.md)；使用编码 Agent 开发插件 → [`plugins/spec/AGENT-DEVELOPMENT.md`](plugins/spec/AGENT-DEVELOPMENT.md)；复制粘贴最小模板 → [`plugins/spec/examples/`](plugins/spec/examples/)。

## 架构设计

```
┌────────────────── browser (Next.js 16) / Electron shell ──────────────┐
│  chat · file workspace · iframe preview · settings · import · MCP     │
└──────────────┬─────────────────────────────────────┬─────────────────┘
               │ /api/*                              │
               ▼                                     ▼
   ┌─────────────────────────────────┐   /api/proxy/{provider}/stream (SSE)
   │  local daemon (Express+SQLite)  │   ─→ any OpenAI-compatible BYOK,
   │                                  │       SSRF-guarded at the edge
   │  /api/skills    /api/plugins    │
   │  /api/design-systems            │
   │  /api/chat (SSE)   /api/proxy/* │
   │  /api/projects/:id/files/...    │
   │  /api/artifacts/{save,lint}     │
   │  /api/import/claude-design      │
   │  MCP stdio server                │
   └─────────┬───────────────────────┘
             │ spawn(cli, [...], { cwd: .od/projects/<id> })
             ▼
   ┌──────────────────────────────────────────────────────────────────┐
   │  claude · codex · cursor-agent · copilot · openclaw · antigravity ·│
   │  gemini · opencode · qwen · qoder · hermes (ACP) · kimi (ACP) ·    │
   │  pi (RPC) · kiro · kilo · vibe (ACP) · cline · trae · deepseek     │
   │  reads SKILL.md + DESIGN.md, writes artifacts to disk             │
   └──────────────────────────────────────────────────────────────────┘
```

| Layer | Stack |
|---|---|
| Frontend | Next.js 16 App Router + React 18 + TypeScript |
| Daemon | Node 24 · Express · SSE streaming · `better-sqlite3` |
| Storage | Files at `.od/projects/<id>/` + SQLite at `.od/app.sqlite` + `media-config.json` (gitignored, auto-created). `OD_DATA_DIR` relocates everything. |
| Preview | Sandboxed `srcdoc` iframe + streaming `<artifact>` parser |
| Export | HTML (inlined) · PDF (browser print) · PPTX (agent-driven) · ZIP · Markdown · MP4 (HyperFrames) |
| Desktop | Electron shell + sandboxed renderer + sidecar IPC (STATUS · EVAL · SCREENSHOT · CONSOLE · CLICK · SHUTDOWN) |
| Lifecycle | One entry point: `pnpm tools-dev` (start / stop / run / status / logs / inspect / check) |

完整架构 → [`docs/architecture.md`](docs/architecture.md)。技能协议 → [`docs/skills-protocol.md`](docs/skills-protocol.md)。Agent 适配器契约 → [`docs/agent-adapters.md`](docs/agent-adapters.md)。

## 贡献指南

Open Design 之所以能持续演进，是因为贡献者——设计师、工程师、提示词作者——始终活跃其中。许多最常用的技能、设计系统和插件均由核心团队之外的人编写。

### 🎯 从哪里开始（高杠杆，最小改动）

| Want to ship… | How | Where |
|---|---|---|
| A new **skill** | Drop a folder with `SKILL.md` + `assets/` + `references/` | [`skills/`](skills/) · spec in [`docs/skills-protocol.md`](docs/skills-protocol.md) |
| A new **design system** | Drop a `DESIGN.md` using the 9-section schema | [`design-systems/<brand>/`](design-systems/) |
| A new **plugin** | Drop `open-design.json` + manifest under a category folder | [`plugins/community/`](plugins/community/) · spec in [`plugins/spec/SPEC.md`](plugins/spec/SPEC.md) · agent dev guide in [`plugins/spec/AGENT-DEVELOPMENT.md`](plugins/spec/AGENT-DEVELOPMENT.md) |
| Support a new **coding-agent CLI** | One adapter entry + stream parser | [`apps/daemon/src/agents.ts`](apps/daemon/src/agents.ts) |
| Fix a bug or polish UI | Browse the [`good-first-issue`](https://github.com/nexu-io/open-design/issues?q=is%3Aissue+is%3Aopen+label%3A%22good+first+issue%22) label | [Issues →](https://github.com/nexu-io/open-design/issues) |
| Translate the docs | Update the `README.<lang>.md` files | [`TRANSLATIONS.md`](TRANSLATIONS.md) |

### 🤖 作为 Agent 进行贡献

如果 *你是正在阅读此文档的 Agent*，最快的路径是：

```bash
# 1. Boot locally
git clone https://github.com/nexu-io/open-design.git
cd open-design && corepack enable && pnpm install
pnpm tools-dev run web

# 2. Find a good-first-issue and assign yourself
gh issue list --label "good first issue" --state open --limit 20
gh issue develop <number>   # create a branch and worktree

# 3. Make the change, run the checks
pnpm guard && pnpm typecheck
pnpm --filter @open-design/<package> test

# 4. Open the PR
gh pr create --fill
```

完整的 Agent 友好型贡献流程、代码规范及 PR 审核标准 → [`CONTRIBUTING.md`](CONTRIBUTING.md)（[Deutsch](CONTRIBUTING.de.md) · [Français](CONTRIBUTING.fr.md) · [简体中文](CONTRIBUTING.zh-CN.md) · [日本語](CONTRIBUTING.ja-JP.md) · [Português](CONTRIBUTING.pt-BR.md)）。

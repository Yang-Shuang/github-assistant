## 项目简介

一个以开发者为中心的开源自主 AI Agent（Autonomous AI Agent）框架，使开发人员能够构建、管理和运行实用的自主智能体。你可以无缝地并行运行多个智能体，并通过工具包扩展其能力。这些智能体能高效执行各类任务，并在每次运行时持续优化自身表现。


### 💡 核心功能

- <b>预置、生成与部署自主 AI Agent</b> - 创建面向生产环境且具备可扩展性的自主智能体。
- <b>通过工具包扩展 Agent 能力</b> - 从我们的应用市场（Marketplace）添加工具包到你的 Agent 工作流中。
- <b>图形用户界面 (GUI)</b> - 通过图形化界面访问和管理你的智能体。
- <b>操作控制台</b> - 向智能体输入指令并授予权限，与其进行交互。
- <b>支持多种向量数据库（Vector DB）</b> - 连接多个向量数据库以增强智能体的性能。
- <b>性能遥测监控</b> - 获取智能体运行表现的洞察数据，并进行针对性优化。
- <b>优化令牌（Token）使用量</b> - 控制 Token 消耗，有效管理成本。
- <b>Agent 记忆存储</b> - 启用记忆存储功能，让 Agent 能够学习并自适应调整。
- <b>模型支持</b> - 提供针对特定业务场景微调的定制模型。
- <b>工作流（Workflows）</b> - 利用 ReAct LLM 预定义的步骤轻松实现任务自动化。

### ⚙️ 安装指南

你可以通过以下三种方式之一安装 SuperAGI。

#### ☁️ SuperAGI 云端版

若想快速体验智能体功能而无需自行搭建环境，可尝试 [Superagi Cloud](https://app.superagi.com/)

1. 访问 [Superagi Cloud](https://app.superagi.com/) 并使用你的 GitHub 账号登录。

2. 在账户设置中，进入“Model Providers”（模型提供商）页面并添加你的 API Key。

配置完成！现在你可以轻松运行你的智能体。

#### 🖥️ 本地部署 (Local)

1. 打开终端并克隆 SuperAGI 代码库。
```
git clone https://github.com/TransformerOptimus/SuperAGI.git 
```

2. 使用以下命令进入克隆的代码库目录：
```
cd SuperAGI
```
3. 复制 `config_template.yaml` 文件并重命名为 `config.yaml`。

4. 确保你的系统已安装 Docker。你可以从[此处](https://docs.docker.com/get-docker/)下载并安装。

5. 启动 Docker Desktop 后，在 SuperAGI 目录下运行以下命令：

   a. 常规使用：
      ```
      docker compose -f docker-compose.yaml up --build
      ```

   b. 若需配合本地大语言模型（Local LLMs）并使用 GPU：
      ```
      docker compose -f docker-compose-gpu.yml up --build
      ```


6. 打开浏览器访问 http://localhost:3000 即可使用 SuperAGI。

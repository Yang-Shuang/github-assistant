# Awesome Agent Skills

与许多批量生成的技能仓库不同，本合集专注于由真实工程团队创建和使用的实际 Agent 技能，而非大规模 AI 生成内容。

本合集收录了来自领先开发团队的官方技能，包括 Anthropic、Google Labs、Vercel、Stripe、Cloudflare、Netlify、Trail of Bits、Sentry、Expo、Hugging Face、Figma 等，以及社区构建的技能。

兼容 Claude Code、Codex、Antigravity、Gemini CLI、Cursor、GitHub Copilot、OpenCode、Windsurf 等。路径和文档见下表。

贡献最多的 Agent 技能仓库，由社区共同构建和维护。

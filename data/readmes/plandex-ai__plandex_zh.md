💻 Plandex 是一款基于终端的 AI 开发工具，能够**规划并执行**跨越多个步骤、涉及数十个文件的大型编程任务。它可直接处理高达 200万 token 的上下文（每个文件约 10万 token），并能使用 tree-sitter 项目映射对包含 2000万 token 或更多内容的目录进行索引。



🔬 **累积差异审查沙盒**将 AI 生成的更改与你的项目文件隔离，直到准备就绪才应用。命令执行过程受控，便于你轻松回滚和调试。Plandex 助你充分发挥 AI 的潜力，同时避免在项目代码中留下混乱。



🧠 **组合最佳模型**：整合 Anthropic、OpenAI、Google 及开源提供商的最优模型，通过稳健的终端工作流构建完整功能与应用。



🚀 Plandex 具备**完全自主性**——可加载相关文件、规划并实施更改、执行命令及自动调试；同时它也非常灵活且高度可配置，在需要时为开发者提供细粒度控制和逐步审查流程。



💪 Plandex 专为应对**大型项目和文件**设计。如果你发现其他工具在项目规模超过一定限度或更改过于复杂时难以胜任，不妨试试 Plandex。



## 适用于大型项目的智能上下文管理



- 🐘 **默认模型包提供 200万 token 的有效上下文窗口**。Plandex 仅按需加载每一步所需的内容。



- 🗄️ **在大型项目和文件中表现可靠**。轻松生成、审查、修订并应用跨越数十个文件的更改。



- 🗺️ **基于 tree-sitter 快速生成项目映射并进行语法验证**，支持 30 多种编程语言。



- 💰 **全面采用上下文缓存技术**（适用于 OpenAI、Anthropic 和 Google 模型），有效降低成本与延迟。



## 紧密控制或完全自主——由你决定



- 🚦 **可配置自主性**：根据任务需求，在全自动模式与细粒度控制之间自由切换。



- 🐞 **终端命令自动调试**（如构建、代码检查、测试、部署及脚本）。若已安装 Chrome，还可自动调试浏览器应用。



## 助你获得生产级成果的工具



- 💬 **项目感知聊天模式**：在实施前帮你完善想法，也适用于提问和了解代码库。



- 🧠 **轻松试用并组合多提供商模型**。精选的模型包提供能力、成本与速度之间的不同权衡，同时包含开源及特定提供商专属包。



- 🛡️ **可靠的文件编辑**，优先保证正确性。虽然大多数编辑快速且成本低廉，但 Plandex 会根据需要验证语法和逻辑，并在出现问题时提供多重回退机制。



- 🔀 **完善的版本控制**：为计划的每次更新保留记录，支持创建分支以探索多条路径或比较不同模型。



- 📂 **Git 集成**：自动生成提交信息，并支持可选的自动提交功能。



## 开发者友好，易于安装



- 🧑‍💻 **REPL 模式**：支持命令和文件加载的模糊自动补全。在任何项目中运行 `plandex` 即可开始使用。



- 🛠️ **CLI 接口**：便于编写脚本或将数据管道输入至上下文。



- 📦 **一行命令、零依赖安装**。Docker 化的本地模式便于自托管服务器，同时提供云托管选项以增强可靠性与便利性。

## 安装 📥



```bash

curl -sL https://plandex.ai/install.sh | bash

```



**注意：** Windows 通过 [WSL](https://learn.microsoft.com/en-us/windows/wsl/install) 支持。Plandex 仅在 WSL 终端下于 Windows 系统正常运行，不支持在 Windows CMD 或 PowerShell 中使用。



[更多安装选项。](https://docs.plandex.ai/install)

## 快速开始 🚀



首先，进入你打算进行开发或讨论项目的**项目目录**。如果是全新项目，可先用 `mkdir your-project-dir` 创建新目录。



```bash

cd your-project-dir

```



对于新项目，你可能还需要初始化 Git 仓库。Plandex 不要求项目必须在 Git 仓库中，但若使用 Git，它能很好地与之集成。



```bash

git init

```



现在在你的项目中启动 Plandex REPL：



```bash

plandex

```



或简写为：



```bash

pdx

```

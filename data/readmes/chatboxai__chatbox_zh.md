## Features

### 🤖 AI Model Support
-   **Support for Multiple LLM Providers**  
    :gear: 无缝集成各类前沿语言模型：
    -   OpenAI (ChatGPT)
    -   Azure OpenAI
    -   Claude
    -   Google Gemini Pro
    -   Ollama（支持访问 llama2、Mistral、Mixtral、codellama、vicuna、yi 和 solar 等本地模型）
    -   ChatGLM-6B

-   **Image Generation with Dall-E-3**  
    :art: 使用 Dall-E-3 创造你想象中的画面。

-   **Enhanced Prompting**  
    :speech_balloon: 提供高级提示词 (Prompt) 功能，帮助你优化和聚焦查询内容，从而获得更精准的回复。

### 🖥️ User Experience
-   **Local Data Storage**  
    :floppy_disk: 你的数据仅保存在本地设备上，确保永不丢失并严格保护隐私。

-   **No-Deployment Installation Packages**  
    :package: 提供可直接运行的安装包，无需复杂配置即可快速开始使用！

-   **Ergonomic UI & Dark Theme**  
    :new_moon: 界面友好，支持夜间模式（深色主题），长时间使用也能减轻眼部疲劳。

-   **Keyboard Shortcuts**  
    :keyboard: 丰富的快捷键设置，助你高效操作，提升工作效率。

-   **Streaming Reply**  
    :arrow_forward: 实时逐步显示回复内容，提供快速、流畅的交互体验。

### 📄 Content & Formatting
-   **Markdown, Latex & Code Highlighting**  
    :scroll: 完整支持 Markdown 和 LaTeX 格式，并配备多种编程语言的语法高亮功能，大幅提升可读性与展示效果。

-   **Prompt Library & Message Quoting**  
    :books: 保存和组织常用提示词以便复用，支持引用历史消息以保留对话上下文。

### 👥 Collaboration & Sharing
-   **Team Collaboration**  
    :busts_in_silhouette: 轻松实现团队协作，共享 OpenAI API 资源。[了解更多](./team-sharing/README.md)

### 🌐 Platform Availability
-   **Cross-Platform Desktop**  
    :computer: Chatbox 全面适配 Windows、Mac 和 Linux 用户。

-   **Web Version**  
    :globe_with_meridians: 在任何带有浏览器的设备上随时随地使用 Web 应用。

-   **Mobile Apps**  
    :phone: 提供原生 iOS 和 Android 应用程序，随时随地畅聊。

### 🌍 Localization
-   **Multilingual Support**  
    :earth_americas: 面向全球用户，提供多种语言支持：
    -   English
    -   简体中文 (Simplified Chinese)
    -   繁體中文 (Traditional Chinese)

    -   Français (French)
    -   Deutsch (German)
    -   Русский (Russian)
    -   Español (Spanish)

## How to Contribute

我们欢迎社区伙伴的贡献！以下是你可以帮助改进 Chatbox 的方式：

### 🐛 Reporting Issues
- 使用 [GitHub Issues](https://github.com/chatboxai/chatbox/issues) 提交 Bug 反馈或功能建议
- 在创建新 Issue 前，请先搜索现有记录以避免重复
- 请提供详细信息，包括复现步骤、预期行为以及必要的截图

### 🔧 Pull Requests
1. Fork 本仓库并从 `main` 分支创建你的开发分支
2. 进行修改，并确保代码符合我们的编码规范
3. 充分测试你的修改

- 优化 README、API 文档或用户指南
- 修正错别字或澄清不明确的说明

## Development

### Prerequisites

在开始之前，请确保已安装以下依赖：

- **Node.js** (v20.x – v22.x) - [下载地址](https://nodejs.org/)
- **pnpm** (v10.x 或更高版本) - 通过 `corepack enable && corepack prepare pnpm@latest --activate` 安装
- **Git** - [下载地址](https://git-scm.com/)

### Quick Setup

1. **Clone the repository**
   ```bash
   git clone https://github.com/chatboxai/chatbox.git
   cd chatbox
   ```

2. **Install dependencies**
   ```bash
   pnpm install
   ```

3. **Start development server**
   ```bash
   pnpm run dev
   ```
   应用将以开发模式启动，并启用热重载 (Hot Reload) 功能。

### Build Commands

| Command | Description |
|---------|-------------|
| `pnpm run dev` | 启动带热重载的开发服务器 |
| `pnpm run package` | 为当前平台构建并打包应用 |
| `pnpm run package:all` | 为所有平台构建并打包应用 |
| `pnpm run build` | 仅构建生产版本，不打包 |
| `pnpm run lint` | 运行 Biome 检查代码质量 |
| `pnpm run test` | 运行 Vitest 测试套件 |

### Project Structure

```
chatbox/
├── src/
│   ├── main/               # Electron main process
│   ├── renderer/           # React renderer (UI)
│   ├── preload/            # Electron preload scripts
│   └── shared/             # Shared utilities
├── doc/                    # Documentation and assets
├── resources/              # App resources and icons
├── team-sharing/           # Team collaboration features
└── package.json            # Project configuration
```

### Development Tips

- 提交代码前请运行 `pnpm run lint` 以确保代码质量
- 遵循现有的代码风格与设计模式
- 在浅色和深色主题下测试你的修改
- 进行 UI 修改时，请确保跨平台兼容性

### Troubleshooting

**Issue**: `pnpm install` fails
- **Solution**: 请确保你正在使用 pnpm（而非 npm 或 yarn），且 Node.js 版本在要求范围内。如果未找到 pnpm，请运行 `corepack enable`。

**Issue**: Build fails on Windows
- **Solution**: 如果使用 Git Bash，请运行 `pnpm config set script-shell "C:\\Program Files\\git\\bin\\bash.exe"`

**Issue**: Changes not reflecting in development
- **Solution**: 停止开发服务器，删除 `node_modules/.vite` 目录后重新启动。

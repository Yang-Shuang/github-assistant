# 掌握 GitHub Copilot
通过我们全新升级的深度课程《掌握 GitHub Copilot》，解锁下一代协作编程体验。该多模块、共计 10 小时的课程现已加入 GitHub Copilot 革命性的 Agent（智能体）模式，将 Copilot 从被动助手转变为你主动协作的 AI 编程伙伴。

无论你是初学者还是经验丰富的开发者，本课程都能帮助你充分利用 GitHub Copilot 的 AI 能力，包括实时自主代码执行、智能问题解决和工作流自动化。你将学习如何使用自然语言提示词与 AI 协作，从而启动多步解决方案——从初步规划和架构建议，到代码生成、测试和迭代。

## 🌱 快速开始

要开始学习，请按照说明将课程仓库 Fork（复刻）到你自己的 GitHub 账号中。这样你就可以根据自己的节奏修改代码并完成挑战任务。

使用 GitHub Copilot 需要拥有有效的订阅服务。

# Awesome DESIGN.md

将 `DESIGN.md` 复制到你的项目根目录，告诉 AI Agent “照着这个样式给我构建一个页面”，即可生成像素级精准的 UI。


## 什么是 DESIGN.md？

[DESIGN.md](https://stitch.withgoogle.com/docs/design-md/overview/) 是 Google Stitch 引入的一个新概念。它是一种纯文本格式的设计系统文档，供 AI Agent 读取并据此生成一致的 UI。

它只是一个 Markdown 文件。无需导出 Figma、JSON Schema 或特殊工具。将其放入项目根目录，任何 AI 编码 Agent 或 Google Stitch 都能立刻理解你的 UI 应该长什么样。Markdown 是 LLM（大语言模型）最易读取的格式，因此无需解析或配置任何东西。

| File | Who reads it | What it defines |
|------|-------------|-----------------|
| `AGENTS.md` | 编码 Agent | 如何构建项目 |
| `DESIGN.md` | 设计 Agent | 项目的视觉与交互风格 |

**本仓库提供开箱即用的 DESIGN.md 文件**，均提取自真实网站。

## What's Inside Each DESIGN.md

每个文件均遵循 [Stitch DESIGN.md 格式](https://stitch.withgoogle.com/docs/design-md/format/) 并包含扩展章节：

| # | Section | What it captures |
|---|---------|-----------------|
| 1 | Visual Theme & Atmosphere | 氛围、密度与设计理念 |
| 2 | Color Palette & Roles | 语义名称 + Hex 色值 + 功能用途 |
| 3 | Typography Rules | 字体族、完整层级表 |
| 4 | Component Stylings | 按钮、卡片、输入框、导航及状态样式 |
| 5 | Layout Principles | 间距比例、网格系统、留白理念 |
| 6 | Depth & Elevation | 阴影体系、表面层级关系 |
| 7 | Do's and Don'ts | 设计规范与反模式 |
| 8 | Responsive Behavior | 断点、触控目标、折叠策略 |
| 9 | Agent Prompt Guide | 快速色值参考、即用型提示词模板 |

每个站点均包含以下文件：

| File | Purpose |
|------|---------|
| `DESIGN.md` | 设计系统（Agent 读取的核心） |
| `preview.html` | 视觉目录，展示色板、字体比例、按钮、卡片 |
| `preview-dark.html` | 同上，但采用深色表面背景 |

### How to Use

1. 将某个网站的 `DESIGN.md` 复制到你的项目根目录
2. 告诉你的 AI Agent 引用它。

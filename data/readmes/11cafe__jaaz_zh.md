## ✨ 核心功能



🎬 一键提示词生成图像与视频
只需一个提示词（Prompt），几秒钟即可生成完整的图片或视频。

 -支持 GPT-4o、Midjourney、VEO3、Kling、seedance 等模型

 -自动优化提示词 & 多轮打磨 refinement

🧙 Magic Canvas（魔法画布）& Magic Video（魔法视频）
免提示词创作——像玩乐高一样搭建。

 -简单涂鸦与自由组合——AI 瞬间理解并生成结果

 -AI 即时理解与生成

 -无需编写复杂提示词

 

 -在视频中简单描述步骤，AI 将按步骤自动生成



🖼️ 无限画布 & 视觉分镜（Storyboarding）
使用无限制的画板规划场景

 -链接布局，可视化媒体管理

 -支持实时协作



🤖 智能 AI Agent（智能体）系统
 -通过对话插入对象、转移风格、控制逻辑

 -兼容本地模型（ComfyUI）与云端模型

 -保持多角色一致性



⚙️ 灵活部署 & 本地资源库
 -完全离线或混合模式设置（Ollama + API 接口）

 -内置媒体与提示词素材库

 -跨平台支持：Windows & macOS



🔐 隐私与安全
- 优先本地运行，数据不会离开你的设备

 -开源透明，无追踪行为

 -商用安全——完全掌握你自己的数据

## 手动安装（适用于 Linux 或本地编译）



🟠 **需要 Python 版本 >=3.12**



首先克隆本仓库：



`git clone https://github.com/11cafe/localart`



`cd react`



`npm install --force`



`npx vite build`



`cd ../server`



`pip install -r requirements.txt`



`python main.py`



## 开发环境配置



🟠 **需要 Python 版本 >=3.12**



VSCode/Cursor 安装扩展：



- Black Formatter by ms-python (ms-python.black-formatter)



`cd react`



`npm install --force && npm run dev`



`cd server`



`pip install -r requirements.txt`



`python main.py`

## ⚡️ 项目愿景

随着 GPT-Image2 的广泛普及，AI 图像生成已从“能不能出图”转向“能否稳定、可控且可复用地出图”。本项目将社区零散案例转化为**提示词即代码（Prompt-as-Code）**资产，便于智能体与自动化工作流高效复用。

核心目标很明确：将散文式提示词压缩为结构化协议。当你需要批量生成、模板系统或生产级工作流时，这种结构比一堆孤立案例更有价值。

- 🧱 原子化架构（Atomic schema）：将主体、光影、材质、排版与视觉细节拆解为可组合的模块
- ⚙️ 工作流友好（Workflow friendly）：专为智能体（Agent）、脚本及自动化系统设计
- 🧬 结构化控制（Structured control）：提升对排版、文案与信息层级的可控性

### 智能体技能快速安装

适用于 Claude Code、Codex、Cursor 及支持 [`skills`](https://www.npmjs.com/package/skills) 的其他工具：

```bash
npx skills add freestylefly/awesome-gpt-image-2 --skill gpt-image-2-style-library --agent claude-code codex --global --yes --copy
```

安装至所有支持的本地智能体：

```bash
npx skills add freestylefly/awesome-gpt-image-2 --global --all --copy
```

### Claude Code 插件市场

在 Claude Code 内运行以下命令：

```text
/plugin marketplace add freestylefly/awesome-gpt-image-2
/plugin install gpt-image-2-style-library@awesome-gpt-image-2
```

### npm CLI

若偏好使用 npm，请先安装 CLI 再将技能同步至本地智能体目录：

```bash
npm install -g gpt-image-2-style-library
gpt-image-2-style-library install all
```

也可无需全局安装直接运行：

```bash
npx gpt-image-2-style-library install all
```

从 GitHub Packages 安装：

```bash
npm login --scope=@freestylefly --registry=https://npm.pkg.github.com
npm install -g @freestylefly/gpt-image-2-style-library --registry=https://npm.pkg.github.com
gpt-image-2-style-library install all
```

`install all` 会将技能写入 Codex 和 Claude Code 通用的本地目录（包括 `~/.codex/skills`、`~/.claude/skills` 及 `~/.agents/skills`）。安装完成后请重启智能体会话。

可通过如下请求调用：

```text
Use gpt-image-2-style-library to create an infographic prompt about Codex.
```

本地源码开发使用：

```bash
npm run generate:style-skill
npm run install:skill
```

技能源码位于 [`agents/skills/gpt-image-2-style_library`](agents/skills/gpt-image-2-style-library/SKILL.md)。其生成的参考数据源自 [`data/style-library.json`](data/style-library.json)，因此网站与智能体工作流共享同一套风格库。

## 🔐 网站认证与生成服务

可视化网站提供需登录的案例分析生成功能，底层由 Supabase Auth、Supabase Postgres 以及用于代理 GPT-Image2 API 的 Vercel Function 驱动。

所需 Vercel 环境变量：

```bash
VITE_SUPABASE_URL=
VITE_SUPABASE_ANON_KEY=
SUPABASE_SERVICE_ROLE_KEY=
SUPER_ADMIN_EMAILS=2689458656@qq.com,canghe0818@gmail.com
CIYUAN_API_KEY=
CIYUAN_BASE_URL=https://ciyuan.today
APP_URL=https://gpt-image2.canghe.ai
STRIPE_SECRET_KEY=
STRIPE_WEBHOOK_SECRET=
VITE_GA_MEASUREMENT_ID=
GA4_PROPERTY_ID=
GOOGLE_ANALYTICS_CLIENT_ID=
GOOGLE_ANALYTICS_CLIENT_SECRET=
GOOGLE_ANALYTICS_REFRESH_TOKEN=
```

部署检查清单：

- 将 [`supabase/migrations/202605090001_user_credits.sql`](supabase/migrations/202605090001_user_credits.sql) 应用于 Supabase 项目。
- 将 [`supabase/migrations/20260509090000_membership_billing.sql`](supabase/migrations/20260509090000_membership_billing.sql) 应用于添加会员计划、积分包、Stripe 订单记录及积分调整 RPC。
- 将 [`supabase/migrations/20260512090000_google_account_center.sql`](supabase/migrations/20260512090000_google_account_center.sql) 应用于添加账号使用统计与超级管理员强制扣款功能。
- 将 [`supabase/migrations/20260512143000_pricing_admin_metrics.sql`](supabase/migrations/20260512143000_pricing_admin_metrics.sql) 应用于更新 `$5 / 300 credits` 定价目录并添加管理员看板指标。
- 将 [`supabase/migrations/20260515090000_case_favorites.sql`](supabase/migrations/20260515090000_case_favorites.sql) 应用于添加用户级案例收藏功能。
- 在 Supabase Auth 重定向 URL 中添加 `https://gpt-image2.canghe.ai` 及本地开发地址（如 `http://127.0.0.1:5173`）。
- 添加 Google OAuth 凭证后，在 Supabase Dashboard 启用 Google 登录提供商。
- 若需强制仅使用 Google 登录，请在 Supabase Auth 设置中禁用 Email 提供商。
- `SUPABASE_SERVICE_ROLE_KEY` 仅限在 Vercel 环境变量等服务器端环境配置。
- 配置 Stripe Checkout，Webhook URL 设为 `https://gpt-image2.canghe.ai/api/billing/webhook`。
- 将 Stripe Webhook 订阅至 `checkout.session.completed`、`invoice.payment_succeeded`、`customer.subscription.updated` 及 `customer.subscription.deleted` 事件。
- `STRIPE_SECRET_KEY` 与 `STRIPE_WEBHOOK_SECRET` 仅限在服务器端 Vercel 环境变量中配置。
- 为 `gpt-image2.canghe.ai` 创建 GA4 属性，将测量 ID 填入 `VITE_GA_MEASUREMENT_ID`，并将数字型属性 ID 复制到 `GA4_PROPERTY_ID`。
- 创建 Google OAuth Web Client，授权重定向 URI 设为 `http://localhost:8080/oauth2callback`，随后将 `GOOGLE_ANALYTICS_CLIENT_ID` 和 `GOOGLE_ANALYTICS_CLIENT_SECRET` 添加至本地 `.env.local`。
- 运行 `npm run ga4:oauth`，打开生成的 URL，授权 `analytics.readonly` 权限，将回调地址粘贴至终端，随后将返回的 `GOOGLE_ANALYTICS_REFRESH_TOKEN` 作为敏感环境变量添加至 Vercel。

## 🚀 如何使用本仓库

1. 从精选案例开始，确定你想要模仿的输出类型。
2. 打开完整画廊寻找相近案例。先复制结构框架，再替换风格词汇。
3. 返回模板页，将你的业务变量填入通用模板或 JSON 模板中。

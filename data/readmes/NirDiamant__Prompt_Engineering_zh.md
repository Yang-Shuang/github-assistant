### 🌱 基础概念

1. **[提示工程简介](https://github.com/NirDiamant/Prompt_Engineering/blob/main/all_prompt_engineering_techniques/intro-prompt-engineering-lesson.ipynb)**
   
   #### 概述 🔎
   全面介绍 AI 与大语言模型语境下提示工程的基础核心概念。

   #### 实践 🛠️
   结合理论讲解与实操演示，涵盖基础概念、结构化提示词、对比分析及问题解决应用。

2. **[基础提示结构](https://github.com/NirDiamant/Prompt_Engineering/blob/main/all_prompt_engineering_techniques/basic-prompt-structures.ipynb)**
   
   #### 概述 🔎
   探索两种基础的提示结构类型：单轮提示与多轮提示（对话）。

   #### 实践 🛠️
   使用 OpenAI 的 GPT 模型和 LangChain 演示单轮/多轮提示、提示模板及对话链。

3. **[提示模板与变量](https://github.com/NirDiamant/Prompt_Engineering/blob/main/all_prompt_engineering_techniques/prompt-templates-variables-jinja2.ipynb)**
   
   #### 概述 🔎
   介绍使用变量创建和运用提示模板的方法，重点聚焦 Python 与 Jinja2 模板引擎。

   #### 实践 🛠️
   涵盖模板创建、变量插入、条件内容处理、列表处理以及与 OpenAI API 的集成。

### 🔧 核心技术

4. **[零样本提示(Zero-Shot Prompting)](https://github.com/NirDiamant/Prompt_Engineering/blob/main/all_prompt_engineering_techniques/zero-shot-prompting.ipynb)**
   
   #### 概述 🔎
   探索零样本提示技术，使大语言模型无需特定示例或先验训练即可执行任务。

   #### 实践 🛠️
   演示直接任务指定、基于角色的提示、格式规范说明，以及使用 OpenAI 和 LangChain 实现多步推理。

5. **[少样本学习与上下文学习](https://github.com/NirDiamant/Prompt_Engineering/blob/main/all_prompt_engineering_techniques/few-shot-learning.ipynb)**
   
   #### 概述 🔎
   涵盖使用 OpenAI GPT 模型和 LangChain 库实现的少样本学习(Few-Shot Learning)与上下文学习(In-Context Learning)技术。

   #### 实践 🛠️
   实现基础与高级的少样本学习、上下文学习，以及示例选择与评估的最佳实践。

6. **[思维链(CoT)提示](https://github.com/NirDiamant/Prompt_Engineering/blob/main/all_prompt_engineering_techniques/cot-prompting.ipynb)**
   
   #### 概述 🔎
   介绍思维链(Chain of Thought, CoT)提示技术，鼓励 AI 模型将复杂问题拆解为逐步推理过程。

   #### 实践 🛠️
   涵盖基础与高级 CoT 技巧，应用于各类问题解决场景，并与标准提示词结果进行对比。

### 🔍 高级策略

7. **[自我一致性与多路径推理](https://github.com/NirDiamant/Prompt_Engineering/blob/main/all_prompt_engineering_techniques/self-consistency.ipynb)**
   
   #### 概述 🔎

   #### 实践 🛠️
   演示设计多样化推理提示、生成多组响应、实现聚合方法以及应用自我一致性检查。

   #### 实践 🛠️

9. **[角色提示(Role Prompting)](https://github.com/NirDiamant/Prompt_Engineering/blob/main/all_prompt_engineering_techniques/role-prompting.ipynb)**
   
   #### 概述 🔎

   #### 实践 🛠️
   演示创建基于角色的提示词、为 AI 分配角色，以及针对各类场景优化角色描述。

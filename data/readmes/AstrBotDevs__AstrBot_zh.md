AstrBot 是一款开源的全栈智能体（Agent）聊天机器人平台，支持接入主流即时通讯应用。它为个人、开发者和团队提供可靠且可扩展的对话式 AI 基础设施。无论你是想打造个人 AI 伴侣、智能客服、自动化助手还是企业知识库，AstrBot 都能帮助你在 IM 工作流中快速构建生产级 AI 应用。

![screenshot_1 5x_postspark_2026-02-27_22-37-45](https://github.com/user-attachments/assets/f17cdb90-52d7-4773-be2e-ff64b566af6b)

## 核心特性

1. 💯 完全免费且开源。
2. ✨ AI 大语言模型（LLM）对话、多模态交互、智能体（Agent）、MCP、技能调用、知识库、人设配置及自动上下文压缩。
3. 🤖 支持接入 Dify、阿里云百炼、Coze 等智能体平台。
4. 🌐 多平台支持：QQ、企业微信（WeCom）、飞书、钉钉、微信公众号、Telegram、Slack，以及[更多](#supported-messaging-platforms)。
5. 📦 插件扩展生态，提供 1000+ 款插件支持一键安装。
6. 🛡️ [智能体沙箱（Agent Sandbox）](https://docs.astrbot.app/use/astrbot-agent-sandbox.html)，提供隔离安全的代码执行、Shell 调用及会话级资源复用功能。
7. 💻 WebUI 支持。
8. 🌈 内置智能体沙箱与网页搜索功能的 Web ChatUI 支持。
9. 🌐 国际化（i18n）多语言支持。

## 快速开始

### 一键部署

对于希望快速体验 AstrBot、熟悉命令行操作并能自行安装 `uv` 环境的用户，推荐采用 `uv` 一键部署方案 ⚡️：

```bash
uv tool install astrbot --python 3.12
astrbot init # 首次运行仅需执行此命令初始化环境
astrbot run
```

> 需提前安装 [uv](https://docs.astral.sh/uv/)。
> AstrBot 需要 Python 3.12 或更高版本。`--python 3.12` 参数可确保 `uv` 使用 Python 3.12 创建工具环境。

> [!NOTE]
> macOS 用户注意：受 macOS 安全策略影响，首次运行 `astrbot` 命令可能耗时较长（约 10-20s）。

更新 `astrbot`：

```bash
uv tool upgrade astrbot --python 3.12
```

> [!WARNING]
> 通过 `uv` 部署的 AstrBot **不支持在 WebUI 中进行版本升级**。如需更新，请从命令行运行上述命令。

### Docker 部署

对于熟悉容器技术、追求更稳定且适合生产环境部署的用户，推荐使用 Docker / Docker Compose 部署 AstrBot。

请参阅官方文档：[使用 Docker 部署 AstrBot](https://docs.astrbot.app/deploy/astrbot/docker.html#%E4%BD%BF%E7%94%A8-docker-%E9%83%A8%E7%BD%B2-astrbot)。

### 在 RainYun 部署

对于希望一键部署且不想自行管理服务器的用户，推荐使用 RainYun 的一键云部署服务 ☁️：

[![Deploy on RainYun](https://rainyun-apps.cn-nb1.rains3.com/materials/deploy-on-rainyun-en.svg)](https://app.rainyun.com/apps/rca/store/5994?ref=NjU1ODg0)

### 桌面应用部署

对于希望在桌面端使用 AstrBot 且主要使用 ChatUI 的用户，推荐使用 AstrBot 桌面应用。

访问 [AstrBot-desktop](https://github.com/AstrBotDevs/AstrBot-desktop) 下载并安装；此方案专为桌面场景设计，不建议用于服务器环境。

### 启动器部署

对于桌面端用户且希望快速部署并实现多实例隔离运行的，推荐使用 AstrBot Launcher。

访问 [AstrBot Launcher](https://github.com/Raven95676/astrbot-launcher) 下载并安装。

### 在 Replit 部署

Replit 部署由社区维护，适用于在线演示与轻量级试用。

[![Run on Repl.it](https://repl.it/badge/github/AstrBotDevs/AstrBot)](https://repl.it/github/AstrBotDevs/AstrBot)

### AUR (Arch Linux)

AUR 部署面向偏好通过系统包管理器安装 AstrBot 的 Arch Linux 用户。

运行以下命令安装 `astrbot-git`，随后在本地环境中启动 AstrBot。

```bash
yay -S astrbot-git
```

**更多部署方式**

如需面板化管理或更深度的自定义，可参考：[BT-Panel（宝塔面板）部署](https://docs.astrbot.app/deploy/astrbot/btpanel.html)、[1Panel 应用市场部署](https://docs.astrbot.app/deploy/astrbot/1panel.html)、[CasaOS NAS/家庭服务器可视化部署](https://docs.astrbot.app/deploy/astrbot/casaos.html)，以及使用 `uv` 的完全自定义源码安装 [手动部署](https://docs.astrbot.app/deploy/astrbot/cli.html)。

# 简介

- 排期管理所有社交媒体帖子（内置多项 AI 功能）
- 通过数据分析评估工作效果。
- 与团队成员协作，交换或购买帖子内容。
- 邀请团队成员进行协作、评论和排期发布。
- 目前托管版（Hosted）与自托管版（Self-hosted）之间没有功能差异。
- 完美适配 N8N、Make.com、Zapier 等平台的自动化工作流（API）。

## 技术栈

- Pnpm workspaces（单体仓库/Monorepo）
- NextJS（React）
- NestJS
- Prisma（默认使用 PostgreSQL）
- Temporal
- Resend（邮件通知）

## Postiz 合规声明

- Postiz 是一款开源、自托管的社交媒体排期工具，支持 X（原 Twitter）、Bluesky、Mastodon、Discord 等平台。
- Postiz 托管服务采用官方且平台认可的 OAuth 流程。
- Postiz 不会对社交媒体平台的内容进行自动化抓取或爬取。
- Postiz 不会收集、存储或代理用户的 API Key 或访问令牌（Access Token）。
- Postiz 绝不会要求用户将 API Key 粘贴到我们的托管产品中。
- Postiz 用户始终直接与社交平台（如 X、Discord 等）进行身份验证，从而确保符合平台规范并保障数据隐私。

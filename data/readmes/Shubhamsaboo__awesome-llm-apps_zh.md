## 💡 为什么会有这个项目

每次开始新的 LLM 项目时，你都不必从头重新构建相同的 RAG 流水线、Agent 循环或 MCP 集成。

**Awesome LLM Apps 是一个即开即用的模板手册** —— 提供可直接 Fork、定制并部署为生产级 LLM 应用的 starter 代码。此处每个模板均为独立完整源码，并非从别处拼凑而来。

- 🛠️ **手工打造，非简单收录** - 每个模板均为原创作品，上线前均经过端到端测试。
- 🧪 **三条命令即可运行** - 没有损坏的 `requirements.txt`，无需“自行摸索”的基础架构搭建。
- 🧠 **覆盖现代 AI 技术栈** - AI Agent、多智能体团队、MCP Agent、语音 AI Agent、RAG、Agent 技能、微调。
- 🌐 **模型无关/提供商中立** - 通过修改配置即可在 Claude、Gemini、GPT、Llama、Qwen、xAI 等之间切换。
- 📚 **分步教程** - 每个精选模板均在 [Unwind AI](https://www.theunwindai.com) 配有免费逐步指南（walkthrough）。
- 💸 **Apache-2.0 协议** - Fork、部署、售卖。无付费墙，无需注册，不收集遥测数据。

> ⭐ **如果这为你节省了时间，请 [给仓库加星](https://github.com/Shubhamsaboo/awesome-llm-apps/stargazers) —— 这正是下一位开发者发现它的方式。**

## 🚀 快速开始

在 **30秒内** 运行你的第一个 Agent：

```bash
git clone https://github.com/Shubhamsaboo/awesome-llm-apps.git
cd awesome-llm-apps/starter_ai_agents/ai_travel_agent
pip install -r requirements.txt
streamlit run travel_agent.py
```

[Apache Camel](https://camel.apache.org/) 是一个开源集成框架，赋能你快速、轻松地集成各种消费或生产数据的系统。

### 简介

Camel 允许你使用多种特定领域语言（DSL，如 Java、XML、Groovy 和 YAML）来定义路由与中介规则。这意味着无论你在 Java 编辑器还是 XML 编辑器中编写代码，IDE 都能为你提供智能的路由规则补全功能。

Apache Camel 使用统一资源标识符（URI）来简化与各种传输或消息模型的集成，包括 HTTP、ActiveMQ、JMS、JBI、SCA、MINA 和 CXF，同时支持可插拔的数据格式选项。Apache Camel 是一个轻量级库，依赖极少，易于嵌入任何 Java 应用中。无论底层使用何种传输类型，你都可以使用相同的 API 进行开发，只需充分理解该 API，即可与所有开箱即用的组件进行交互。

Apache Camel 具备强大的 Bean 绑定功能，并能与 Spring、Quarkus 和 CDI 等流行框架无缝集成。

Apache Camel 提供了广泛的测试支持，让你能够轻松地对路由进行单元测试。

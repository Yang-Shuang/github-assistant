你的个人 AI 助手 —— 安装简便，支持本地或云端部署，跨渠道连接，轻松扩展。

> **核心能力：**
>
> **完全由你掌控** — 记忆与个性化功能完全受你控制。可本地部署（数据保留在你的设备上）或云端部署（选择你的服务器）。无第三方托管，不上传数据。
>
> **技能扩展** — 内置调度、PDF/Office 处理、新闻摘要等功能；自定义技能自动加载，无锁定风险。技能决定了 QwenPaw 能做什么。
>
> **多智能体协作** — 创建多个独立智能体，各自拥有专属角色；启用协作技能以实现智能体间通信，共同应对复杂任务。
>
> **多层安全防护** — 工具守卫、文件访问控制、技能安全扫描，确保运行安全。
>
> **全渠道覆盖** — 钉钉、飞书、微信、Discord、Telegram 等。一个 QwenPaw，按需连接。
>
> **记忆进化与主动服务** — 智能体从交互中学习，反思经验，并主动为你提供服务。使用越多，越聪明。
>

## 快速开始

### 方式一：pip 安装

如果你希望自行管理 Python 环境：

```bash
pip install qwenpaw
qwenpaw init --defaults
qwenpaw app
```

然后在浏览器中打开控制台 **http://127.0.0.1:8088/** 配置你的模型。若要在钉钉、飞书、微信等渠道对话，请参阅 [渠道设置](https://qwenpaw.agentscope.io/docs/channels) 文档。

### 方式二：脚本安装

无需配置 Python，一条命令完成全部安装。脚本会自动下载 `uv`（Python 包管理器），创建虚拟环境，并安装 QwenPaw 及其所有依赖项（包括 Node.js 和前端资源）。注意：在受限网络或企业防火墙环境下可能无法正常工作。

**macOS / Linux：**

```bash
curl -fsSL https://qwenpaw.agentscope.io/install.sh | bash
```

**Windows (CMD)：**

```CMD
curl -fsSL https://qwenpaw.agentscope.io/install.bat -o install.bat && install.bat
```

**Windows (PowerShell)：**

```powershell
irm https://qwenpaw.agentscope.io/install.ps1 | iex
```

> **注意**：安装程序会自动检查 `uv` 的状态。如果未安装，将尝试自动下载并配置。若自动安装失败，请根据屏幕提示操作或执行 `python -m pip install -U uv`，然后重新运行安装程序。

> **⚠️ Windows LTSC/企业版用户特别提示**
>
> 如果你使用的是 Windows LTSC 版本或受严格安全策略管控的企业环境，PowerShell 可能会以 **受限语言模式（Constrained Language Mode）** 运行，可能导致以下问题：
> 1. **如果使用 CMD (.bat)：脚本执行成功但无法写入 `Path`**
> 
>    脚本会完成文件安装。由于 **受限语言模式**，它无法自动更新环境变量。请手动按以下步骤配置：
>    - **定位安装目录**：
>      - 检查 `uv` 是否可用：在 CMD 中输入 `uv --version`。如果出现版本号，则**只需配置 QwenPaw 路径**。如果提示 `'uv' is not recognized as an internal or external command, operable program or batch file,`，则需同时配置两条路径。
>      - uv 路径（根据安装位置选择其一；若 `uv` 失败时使用）：通常为 `%USERPROFILE%\.local\bin`、`%USERPROFILE%\AppData\Local\uv` 或 Python 安装目录下的 `Scripts` 文件夹
>      - QwenPaw 路径：通常位于 `%USERPROFILE%\.qwenpaw\bin`。
>    - **手动添加到系统 Path 环境变量**：
>      - 按 `Win + R`，输入 `sysdm.cpl` 并回车打开“系统属性”。
>      - 点击“高级” -> “环境变量”。
>      - 在“系统变量”中，找到并选中 `Path`，然后点击“编辑”。
>      - 点击“新建”，依次输入上述两个目录路径，然后确定保存。
> 2. **如果使用 PowerShell (.ps1)：脚本执行中断**
> 
>   由于 **受限语言模式**，脚本可能无法自动下载 `uv`。
>   - **手动安装 uv**：参考 [GitHub Release](https://github.com/astral-sh/uv/releases) 下载 `uv.exe` 并放置于 `%USERPROFILE%\.local\bin` 或 `%USERPROFILE%\AppData\Local\uv`；或者确保已安装 Python 并运行 `python -m pip install -U uv`。
>   - **配置 `uv` 环境变量**：将 `uv` 目录和 `%USERPROFILE%\.qwenpaw\bin` 添加到系统 `Path` 变量中。
>   - **重新运行安装**：打开新的终端并再次执行安装脚本，完成 `QwenPaw` 的安装。
>   - **配置 `QwenPaw` 环境变量**：将 `%USERPROFILE%\.qwenpaw\bin` 添加到系统 `Path` 变量中。

安装完成后，打开新终端并运行：

```bash
qwenpaw init --defaults   # 或：qwenpaw init（交互式）
qwenpaw app
```

### 方式三：Docker

镜像位于 **Docker Hub**（`agentscope/qwenpaw`）。镜像标签：`latest`（稳定版）；`pre`（PyPI 预发布版）。

```bash
docker pull agentscope/qwenpaw:latest
docker run -p 127.0.0.1:8088:8088 \
  -v qwenpaw-data:/app/working \
  -v qwenpaw-secrets:/app/working.secret \
  -v qwenpaw-backups:/app/working.backups \
  agentscope/qwenpaw:latest
```

中国境内用户也可使用阿里云容器镜像服务（ACR）：`agentscope-registry.ap-southeast-1.cr.aliyuncs.com/agentscope/qwenpaw`（标签相同）。

随后打开 **http://127.0.0.1:8088/** 进入控制台。配置、记忆和技能数据存储在 `qwenpaw-data` 卷中；模型提供商设置和 API Key 存储在 `qwenpaw-secrets` 卷中；备份归档文件存储在 `qwenpaw-backups` 卷中。如需传递环境变量（例如 `DASHSCOPE_API_KEY`），请在 `docker run` 中添加 `-e VAR=value` 或 `--env-file .env`。

> **连接到宿主机上的 Ollama 或其他服务**
>
> 在 Docker 容器内部，`localhost` 指的是容器本身，而非你的宿主机。如果你在宿主机上运行了 Ollama（或其他模型服务），并希望 Docker 中的 QwenPaw 能够访问它们，可使用以下方法之一：
>
> **方案 A** — 显式绑定宿主机地址（所有平台）：
> ```bash
> docker run -p 127.0.0.1:8088:8088 \
>   --add-host=host.docker.internal:host-gateway \
>   -v qwenpaw-data:/app/working \
>   -v qwenpaw-secrets:/app/working.secret \
>   -v qwenpaw-backups:/app/working.backups \
>   agentscope/qwenpaw:latest
> ```
> 然后在 QwenPaw **设置 → 模型** 中，将基础 URL（Base URL）改为 `http://host.docker.internal:<端口>` —— 例如 Ollama 使用 `http://host.docker.internal:11434`，LM Studio 使用 `http://host.docker.internal:1234/v1`。
>
> **方案 B** — 主机网络模式（仅限 Linux）：
> ```bash
> docker run --network=host \
>   -v qwenpaw-data:/app/working \
>   -v qwenpaw-secrets:/app/working.secret \
>   -v qwenpaw-backups:/app/working.backups \
>   agentscope/qwenpaw:latest
> ```
> 无需端口映射（`-p`）；容器直接共享宿主机网络。请注意，所有容器端口将在宿主机上暴露，若端口已被占用可能会产生冲突。

该镜像为从零构建。如需自行构建镜像，请参考 `scripts/README.md` 中的 [构建 Docker 镜像](scripts/README.md#build-docker-image) 章节，然后推送到你的仓库。

### 方式六：桌面应用（Beta）

> **Beta 提示**：桌面应用目前处于 Beta 测试阶段，存在以下已知限制：
> - **兼容性测试不完整**：尚未在所有系统版本和硬件配置上完成全面测试
> - **潜在性能问题**：启动时间、内存占用等性能表现可能仍需进一步优化
> - **功能开发中**：部分功能可能不稳定或缺失

如果你不熟悉命令行工具，可以下载并使用 QwenPaw 的桌面应用，无需手动配置 Python 环境或运行命令。

#### 下载

从 [GitHub Releases](https://github.com/agentscope-ai/QwenPaw/releases) 下载桌面应用：
- **Windows**：`QwenPaw-Setup-<version>.exe`
- **macOS**：`QwenPaw-<version>-macOS.zip`（推荐 Apple Silicon）

#### 特性

- ✅ **零配置**：下载后双击运行，无需安装 Python 或配置环境变量
- ✅ **跨平台**：支持 Windows 10+ 和 macOS 14+
- ✅ **可视化界面**：自动打开浏览器界面，无需手动输入地址
- ⚠️ **Beta 阶段**：功能持续优化中，欢迎反馈

#### 首次启动

**重要提示**：首次启动可能需要 10-60 秒（取决于你的系统配置）。应用需要初始化 Python 环境并加载依赖。请耐心等待浏览器窗口自动打开。

#### macOS：绕过系统安全限制

当你从 Releases 下载 QwenPaw macOS 应用时，macOS 可能会显示：“Apple 无法验证 ‘QwenPaw’ 不包含恶意软件”。这是因为该应用未经过公证。你仍可按以下方式打开：

- **右键打开（推荐）**
  右键（或 Control+点击）QwenPaw 应用 → **打开** → 在弹出的对话框中再次点击 **打开**。这会告知 Gatekeeper 你信任该应用；之后即可像往常一样双击启动。

- **在系统设置中允许**
  如果仍被拦截，请前往 **系统设置 → 隐私与安全性**，滚动到类似 “QwenPaw 已被阻止，因为它来自身份不明的开发者” 的消息处，点击 **仍然打开** 或 **允许**。

- **移除隔离属性（不推荐普通用户使用）**
  在终端中运行：
  `xattr -cr /Applications/QwenPaw.app`
  （或使用解压后的 `.app` 实际路径）。这会清除“从互联网下载”的隔离标记，使警告通常不再出现，但安全性不如使用 **右键 → 打开** 可控。

详细使用说明、故障排除和常见问题，请参阅 [桌面应用指南](https://qwenpaw.agentscope.io/docs/desktop)。

## API Key

如果你使用的是 **云端 LLM API**（例如 Qianwen、Gemini、OpenAI），必须在对话前配置 API Key。未设置有效密钥时，QwenPaw 将无法正常工作。详情请参阅 [官方文档](https://qwenpaw.agentscope.io/docs/models)。

**如何配置：**

1. **控制台（推荐）** — 运行 `qwenpaw app` 后，打开 **http://127.0.0.1:8088/** → **设置** → **模型**。选择提供商，输入 **API Key**，并启用该提供商及对应模型。
2. **`qwenpaw init`** — 运行 `qwenpaw init` 时，它会引导你配置 LLM 提供商和 API Key。按提示选择提供商并输入密钥即可。
3. **环境变量** — 对于 DashScope，你可以在 shell 或工作目录下的 `.env` 文件中设置 `DASHSCOPE_API_KEY`。

需要额外密钥的工具（例如用于网页搜索的 `TAVILY_API_KEY`）可在控制台 **设置 → 环境变量** 中配置，详见 [Config](https://qwenpaw.agentscope.io/docs/config)。

> **仅使用本地模型？** 如果你使用的是 [本地模型](#local-models)（llama.cpp / Ollama / LM Studio），则**不需要**任何 API Key。

## 安全特性

QwenPaw 内置多层安全机制，以保护你的数据与系统：

- **工具守卫** — 自动拦截危险 Shell 命令（例如 `rm -rf /`、fork 炸弹、反向 shell 等）
- **文件访问守卫** — 限制智能体访问敏感路径（例如 `~/.ssh`、密钥文件、系统目录等）
- **技能安全扫描** — 安装技能前自动扫描，检测提示词注入、命令注入、硬编码密钥、数据外泄等风险
- **本地部署** — 所有数据与记忆均存储在本地，无第三方上传（使用云端 LLM API 时，对话内容会发送至对应的 API 提供商）
- **Web 认证** — 控制台可选登录保护。默认禁用；设置 `QWENPAW_AUTH_ENABLED=true` 即可启用。详见 [Web 认证](https://qwenpaw.agentscope.io/docs/security#Web-Authentication)。

详情请参阅 [安全文档](https://qwenpaw.agentscope.io/docs/security)。

## 从源码安装

```bash
git clone https://github.com/agentscope-ai/QwenPaw.git
cd QwenPaw

# 先构建控制台前端（Web UI 必需）
cd console && npm ci && npm run build
cd ..

# 将控制台构建产物复制到包目录
mkdir -p src/qwenpaw/console
cp -R console/dist/. src/qwenpaw/console/

# 安装 Python 包
pip install -e .
```

- **开发环境**（测试、格式化）：`pip install -e ".[dev,full]"`
- **然后**：运行 `qwenpaw init --defaults`，随后执行 `qwenpaw app`。

> **更新提示**：在使用 `git pull` 更新至新版本后，请重新构建前端、重新安装包（`pip install -e .`）、重启 `qwenpaw app`，并使用 `Ctrl+Shift+R`（macOS 为 `Cmd+Shift+R`）清除浏览器缓存。

## 遥测数据（Telemetry）

QwenPaw 会在 `qwenpaw init` 期间收集**匿名**使用数据，以帮助我们了解用户群体并优先进行改进。数据仅在 **每个版本发送一次** —— 当你升级 QwenPaw 时，会重新收集遥测数据以便我们追踪版本采用情况。

**我们收集的内容：**

- QwenPaw 版本号（例如 0.0.7）
- 安装方式（pip、Docker 或桌面应用）
- 操作系统及版本（例如 macOS 14.0, Ubuntu 22.04）
- Python 版本（例如 3.13）
- CPU 架构（例如 x86_64, arm64）
- GPU 可用性（是/否）

**我们不收集的内容：** 无个人数据、无文件内容、无凭证信息、无 IP 地址、无可识别身份的信息。

在交互式运行 `qwenpaw init` 时，你会被询问是否同意参与遥测。若选择 `--defaults`，则自动接受遥测。该提示每个版本仅出现一次，且不会影响 QwenPaw 的任何功能。

## 参与步骤



- 选择一个 Issue（问题），并申请将其分配给你自己。

- 查看 [projects](/projects/) 目录中已有的脚本。

- **Star（收藏）** 本仓库。

- 在 [python-mini-projects](https://github.com/Python-World/python-mini-projects) 仓库页面，点击 **Fork（复刻）** 按钮。

    <br><img src="https://help.github.com/assets/images/help/repository/fork_button.jpg" title="Fork image" width="400"/>

- 将你的 Fork 仓库 **Clone（克隆）** 到本地计算机。该按钮会显示你需要运行的 URL。

    <br><img src="https://docs.github.com/assets/images/help/repository/code-button.png" title="Code button" width="400"/>



    例如，在终端中运行以下命令：



    ```bash

    git clone https://github.com/<your-github-username>/python-mini-projects.git

    ```



    **请替换 \<your-github-username\>！**



    了解更多关于 [Fork（复刻）](https://help.github.com/en/github/getting-started-with-github/fork-a-repo) 和 [克隆仓库](https://docs.github.com/en/github/creating-cloning-and-archiving-repositories/cloning-a-repository) 的信息。

- 在进行任何更改之前，[保持你的 Fork 与上游同步](https://www.freecodecamp.org/news/how-to-sync-your-fork-with-the-original-git-repository/)以避免合并冲突：



    ```bash

    git remote add upstream https://github.com/Python-World/python-mini-projects.git

    git fetch upstream

    git pull upstream master

    git push

    ```

    

    或者，GitHub 现在也提供了同步功能——在你的仓库中，“Code”按钮上方点击“Fetch upstream（获取上游）”。



- 如果遇到**合并冲突（merge conflict）**，你必须解决该冲突。网上有很多指南，你也可以尝试这篇来自 [opensource.com](https://opensource.com/article/20/4/git-merge-conflict) 的教程。



- 切换到开发分支（*根据你的 Issue 名称命名你的分支*）。



    ```bash

    git checkout -b <branch-name>

    ```



- 在 [projects 目录](https://github.com/Python-World/python-mini-projects/tree/master/projects) 中，根据 Issue 名称创建一个文件夹。

- 编写你的代码，并将其添加到本地 projects 目录下的对应文件夹中。

- 别忘了在你的文件夹中添加一个 `README.md` 文件，并参考 [README 模板](https://github.com/Python-World/python-mini-projects/blob/master/README_TEMPLATE.md)。

- 使用 `git add` 和 `git commit` 添加更改（如果可能，请[撰写良好的提交信息](https://chris.beams.io/posts/git-commit/)）：



    ```bash

    git add -A

    git commit -m "<your message>"

    ```



- 将代码推送到_你的仓库_。



    ```bash

    git push origin <branch-name>

    ```



- 前往_你 Fork 的_ GitHub 页面，并**创建 Pull Request（拉取请求）**：



    ![pull request image](https://help.github.com/assets/images/help/pull_requests/choose-base-and-compare-branches.png)



    在 [GitHub 帮助页面](https://help.github.com/en/github/collaborating-with-issues-and-pull-requests/creating-a-pull-request)了解更多关于 Pull Request 的信息。

- 现在等待，直到我们中的某位成员*审查你的 Pull Request*！如果存在冲突，你会收到通知。

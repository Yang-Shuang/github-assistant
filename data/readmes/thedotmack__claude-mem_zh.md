<p align="center">
  Claude-Mem 通过自动捕获工具使用记录、生成语义摘要，并将其提供给后续会话，从而无缝地在跨会话中保留上下文。这使得 Claude 即使在会话结束或重新连接后，也能保持对项目知识的连续性。
</p>

## 快速开始

只需一条命令即可安装：

```bash
npx claude-mem install
```

或者为 Gemini CLI 安装（自动检测 `~/.gemini`）：

```bash
npx claude-mem install --ide gemini-cli
```
或者为 OpenCode 安装：

```bash
npx claude-mem install --ide opencode
```

或者在 Claude Code 内部通过插件市场安装：

```bash
/plugin marketplace add thedotmack/claude-mem

/plugin install claude-mem
```

重启 Claude Code 或 Gemini CLI。之前会话的上下文将自动出现在新会话中。

> **注意：** Claude-Mem 也已发布在 npm 上，但 `npm install -g claude-mem` 仅安装**SDK/库文件**——它不会注册插件钩子（hook）或设置工作进程服务。请始终通过 `npx claude-mem install` 或上述 `/plugin` 命令进行安装。

### 🦞 OpenClaw Gateway

只需一条命令即可在 [OpenClaw](https://openclaw.ai) 网关上安装 claude-mem 持久化记忆插件：

```bash
curl -fsSL https://install.cmem.ai/openclaw.sh | bash
```

安装程序将自动处理依赖项、插件配置、AI 提供商设置、工作进程启动，以及可选的 Telegram、Discord、Slack 等平台的实时记录推送。详情请参阅 [OpenClaw 集成指南](https://docs.claude-mem.ai/openclaw-integration)。

**核心功能：**

- 🧠 **持久化记忆（Persistent Memory）** - 上下文跨会话保留
- 📊 **渐进式披露（Progressive Disclosure）** - 分层检索记忆，并显示 Token 消耗成本
- 🔍 **基于技能的搜索（Skill-Based Search）** - 使用 `mem-search` 技能查询项目历史记录
- 🖥️ **网页查看器界面（Web Viewer UI）** - 在 http://localhost:37777 实时查看记忆流
- 💻 **Claude Desktop 技能** - 从 Claude Desktop 对话中搜索记忆
- 🔒 **隐私控制（Privacy Control）** - 使用 `<private>` 标签排除敏感内容，防止其被存储
- ⚙️ **上下文配置（Context Configuration）** - 精细控制注入的上下文内容
- 🤖 **自动运行** - 无需手动干预
- 🔗 **引用溯源（Citations）** - 通过 ID 引用历史记录（可通过 http://localhost:37777/api/observation/{id} 访问，或在网页查看器中查看全部）
- 🧪 **测试频道（Beta Channel）** - 通过版本切换体验如无限模式（Endless Mode）等实验性功能

## 工作原理

**核心组件：**

1. **5 个生命周期钩子（Lifecycle Hooks）** - SessionStart、UserPromptSubmit、PostToolUse、Stop、SessionEnd（共 6 个钩子脚本）
2. **智能安装（Smart Install）** - 缓存依赖检查器（预钩子脚本，非生命周期钩子）
3. **工作进程服务（Worker Service）** - 由 Bun 管理，提供端口 37777 上的 HTTP API、网页查看器界面及 10 个搜索接口
4. **SQLite 数据库** - 存储会话记录、观察数据与摘要
5. **mem-search 技能** - 支持自然语言查询与渐进式披露
6. **Chroma 向量数据库** - 结合语义与关键词的混合搜索，实现智能上下文检索

详情请参阅[架构概览](https://docs.claude-mem.ai/architecture/overview)。

## MCP 搜索工具

Claude-Mem 通过 **4 个 MCP 工具**提供智能记忆搜索，并遵循节省 Token 的**三层工作流模式**：

**三层工作流：**

1. **`search`** - 获取包含 ID 的精简索引（约 50-100 Token/结果）
2. **`timeline`** - 获取有趣结果周围的时间线上下文
3. **`get_observations`** - 仅针对筛选后的 ID 获取完整详情（约 500-1,000 Token/结果）

**工作原理：**
- Claude 使用 MCP 工具搜索你的记忆库
- 首先使用 `search` 获取结果索引
- 使用 `timeline` 查看特定记录周围发生的情况
- 使用 `get_observations` 获取相关 ID 的完整详情
- **提前过滤再获取详情，可节省约 10 倍的 Token**

**可用的 MCP 工具：**

1. **`search`** - 使用全文查询搜索记忆索引，支持按类型/日期/项目筛选
2. **`timeline`** - 获取特定记录或查询结果周围的时间线上下文
3. **`get_observations`** - 通过 ID 获取完整的观察记录详情（务必批量传入多个 ID）

**使用示例：**

```typescript
// Step 1: Search for index
search(query="authentication bug", type="bugfix", limit=10)

// Step 2: Review index, identify relevant IDs (e.g., #123, #456)

// Step 3: Fetch full details
get_observations(ids=[123, 456])
```

详情请参阅[搜索工具指南](https://docs.claude-mem.ai/usage/search-tools)。

## 配置说明

设置文件位于 `~/.claude-mem/settings.json`（首次运行时自动生成默认配置）。在此可配置 AI 模型、工作进程端口、数据目录、日志级别及上下文注入策略。

所有可用设置与示例请参见**[配置指南](https://docs.claude-mem.ai/configuration)**。

### 模式与语言配置

Claude-Mem 通过 `CLAUDE_MEM_MODE` 设置支持多种工作流模式与语言。

该选项同时控制：
- 工作流行为（例如 code、chill、investigation）
- 生成记录时使用的语言

#### 配置方法

编辑位于 `~/.claude-mem/settings.json` 的设置文件：

```json
{
  "CLAUDE_MEM_MODE": "code--zh"
}
```

模式定义在 `plugin/modes/` 目录中。要在本地查看所有可用模式，请运行：

```bash
ls ~/.claude/plugins/marketplaces/thedotmack/plugin/modes/
```

#### 可用模式

| Mode | Description |
|------------|-------------------------|
| `code` | 默认英文模式 |
| `code--zh` | 简体中文模式 |
| `code--ja` | 日语模式 |

特定语言的模式遵循 `code--[lang]` 格式，其中 `[lang]` 为 ISO 639-1 语言代码（例如中文为 `zh`、日语为 `ja`、西班牙语为 `es`）。

> **注意：** `code--zh`（简体中文）已内置——无需额外安装或更新插件。

#### 更改模式后

重启 Claude Code 即可应用新的模式配置。

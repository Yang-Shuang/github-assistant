Dify 是一款开源的 LLM（大语言模型）应用开发平台。其直观的界面融合了 AI 工作流、RAG（检索增强生成）管道、Agent（智能体）能力、模型管理以及可观测性功能（包括 [Opik](https://www.comet.com/docs/opik/integrations/dify)、[Langfuse](https://docs.langfuse.com) 和 [Arize Phoenix](https://docs.arize.com/phoenix)），让你能够快速从原型走向生产环境。以下是核心功能列表：

## 快速开始

> 在安装 Dify 之前，请确保你的机器满足以下最低系统要求：
>
> - CPU ≥ 2 核
> - 内存 ≥ 4 GiB

<br/>

启动 Dify 服务器的最简单方法是通过 [Docker Compose](docker/docker-compose.yaml)。在使用以下命令运行 Dify 之前，请确保你的机器已安装 [Docker](https://docs.docker.com/get-docker/) 和 [Docker Compose](https://docs.docker.com/compose/install/)：

```bash
cd dify
cd docker
cp .env.example .env
docker compose up -d
```

运行后，你可以在浏览器中访问 Dify 控制台地址 [http://localhost/install](http://localhost/install)，并开始初始化流程。

#### 寻求帮助

如果在设置 Dify 时遇到问题，请参阅我们的[常见问题解答（FAQ）](https://docs.dify.ai/getting-started/install-self-hosted/faqs)。如果问题仍未解决，请联系[社区和我们](#community--contact)。

> 如果你希望为 Dify 做出贡献或进行额外开发，请参阅我们的[从源代码部署指南](https://docs.dify.ai/getting-started/install-self-hosted/local-source-code)

## 核心功能

**1. 工作流（Workflow）**：
在可视化画布上构建和测试强大的 AI 工作流，充分利用以下所有功能及更多扩展。

**2. 全面的模型支持**：
无缝集成数十个推理提供商提供的数百款专有/开源 LLM 以及自托管方案，涵盖 GPT、Mistral、Llama3 以及所有兼容 OpenAI API 的模型。完整的支持模型提供商列表请见[此处](https://docs.dify.ai/getting-started/readme/model-providers)。

![providers-v5](https://github.com/langgenius/dify/assets/13230914/5a17bdbe-097a-4100-8363-40255b70f6e3)

**3. Prompt（提示词）IDE**：
直观的界面用于编写提示词、比较模型性能，并为基于聊天的应用添加文本转语音等附加功能。

**4. RAG 管道**：
强大的 RAG 能力覆盖从文档导入到检索的全流程，开箱即用支持从 PDF、PPT 及其他常见文档格式中提取文本。

**5. Agent（智能体）能力**：
你可以基于 LLM Function Calling 或 ReAct 框架定义 Agent，并为其添加预置或自定义工具。Dify 为 AI Agent 提供了 50+ 内置工具，例如 Google Search、DALL·E、Stable Diffusion 和 WolframAlpha。

**6. LLMOps（大模型运维）**：
随时间监控和分析应用日志与性能。你可以基于生产数据及标注持续优化提示词、数据集和模型。

**7. 后端即服务（Backend-as-a-Service）**：
Dify 的所有功能均提供对应的 API，让你能够轻松将 Dify 集成到自身的业务逻辑中。

  使用这份[入门指南](#快速开始)即可在你的环境中快速运行 Dify。如需更多参考和深入说明，请使用我们的[文档](https://docs.dify.ai)。

- **面向企业/组织的 Dify<br/>**  
  我们提供额外的面向企业级功能。[给我们发送邮件](mailto:business@dify.ai?subject=%5BGitHub%5DBusiness%20License%20Inquiry)以探讨你的企业需求。<br/>

## 高级设置

### 自定义配置

如需自定义配置，请编辑 `docker/.env`。核心启动默认值位于 [`docker/.env.example`](docker/.env.example)，可选的高级变量按主题分类存放在 `docker/envs/` 目录下。进行任何更改后，请在 `docker` 目录中重新运行 `docker compose up -d`。所有可用环境变量的完整列表请见[此处](https://docs.dify.ai/getting-started/install-self-hosted/environments)。

### 使用 Grafana 进行指标监控

将仪表板导入 Grafana，以 Dify 的 PostgreSQL 数据库作为数据源，按应用、租户、消息等维度进行细粒度指标监控。

- [Grafana Dashboard by @bowenliang123](https://github.com/bowenliang123/dify-grafana-dashboard)

### 使用 Kubernetes 部署

如需配置高可用架构，社区贡献了多个 [Helm Charts](https://helm.sh/) 和 YAML 文件，支持将 Dify 部署在 Kubernetes 上。

- [Helm Chart by @LeoQuote](https://github.com/douban/charts/tree/master/charts/dify)
- [Helm Chart by @BorisPolonsky](https://github.com/BorisPolonsky/dify-helm)
- [Helm Chart by @magicsong](https://github.com/magicsong/ai-charts)
- [YAML file by @Winson-030](https://github.com/Winson-030/dify-kubernetes)
- [YAML file by @wyy-holding](https://github.com/wyy-holding/dify-k8s)
- [🚀 NEW! YAML files (Supports Dify v1.6.0) by @Zhoneym](https://github.com/Zhoneym/DifyAI-Kubernetes)

#### 使用 Terraform 部署

使用 [terraform](https://www.terraform.io/) 一键将 Dify 部署到云平台。

##### Azure Global

- [Azure Terraform by @nikawang](https://github.com/nikawang/dify-azure-terraform)

##### Google Cloud

- [Google Cloud Terraform by @sotazum](https://github.com/DeNA/dify-google-cloud-terraform)

#### 使用 AWS CDK 部署

使用 [CDK](https://aws.amazon.com/cdk/) 将 Dify 部署到 AWS。

##### AWS

- [AWS CDK by @KevinZhao (EKS based)](https://github.com/aws-samples/solution-for-deploying-dify-on-aws)
- [AWS CDK by @tmokmss (ECS based)](https://github.com/aws-samples/dify-self-hosted-on-aws)

#### 使用阿里云计算巢

通过[阿里云计算巢](https://computenest.console.aliyun.com/service/instance/create/default?type=user&ServiceName=Dify%E7%A4%BE%E5%8C%BA%E7%89%88)快速将 Dify 部署到阿里云。

#### 使用阿里云数据管理（DMS）

通过[阿里云数据管理服务](https://www.alibabacloud.com/help/en/dms/dify-in-invitational-preview/)一键将 Dify 部署到阿里云。

#### 使用 Azure DevOps Pipeline 部署至 AKS

通过[@LeoZhang 提供的 Azure DevOps Pipeline Helm Chart](https://github.com/Ruiruiz30/Dify-helm-chart-AKS)一键将 Dify 部署至 AKS。

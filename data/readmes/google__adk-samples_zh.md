# Agent Development Kit (ADK) 示例

[![License](https://img.shields.io/badge/License-Apache_2.0-blue.svg)](LICENSE)

<img src="https://github.com/google/adk-docs/blob/main/docs/assets/agent-development-kit.png" alt="Agent Development Kit Logo" width="150">

欢迎来到 ADK 示例智能体仓库！本集合提供了一系列基于 [Agent Development Kit (ADK)](https://adk.dev) 构建的即用型智能体，旨在加速你的开发流程。这些智能体涵盖了多种常见用例和复杂度等级，从简单的对话机器人到复杂的多智能体工作流均有涉及。

## ✨ 入门指南

本仓库包含适用于 **Python**、**TypeScript**、**Go**、**Java**、**Kotlin** 和 **Android** 的 ADK 示例智能体。请导航至 **[Python](python/)**、**[TypeScript](typescript/)**、**[Go](go/)**、**[Java](java/)**、**[Kotlin](kotlin/)** 和 **[Android](android/)** 子文件夹，查看特定语言的设置说明，并了解更多可用的示例智能体。

> [!IMPORTANT]
> 本仓库中的智能体均基于 **Agent Development Kit (ADK)** 构建。在运行任何示例之前，你必须先安装 ADK。如需操作指南，请参阅 [**ADK Installation Guide**](https://adk.dev/get-started)。

欲了解更多内容，请查阅 [ADK Documentation](https://adk.dev) 以及各语言的 GitHub 仓库：

- [ADK Python](https://github.com/google/adk-python)
- [ADK Typescript](https://github.com/google/adk-js)
- [ADK Go](https://github.com/google/adk-go)
- [ADK Java](https://github.com/google/adk-java)
- [ADK Kotlin](https://github.com/google/adk-kotlin)

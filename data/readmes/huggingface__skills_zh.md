# Hugging Face Skills

Hugging Face Skills 是用于定义数据集构建、模型训练和评估等 AI/ML 任务的规范。它们与所有主流编码智能体（coding agent）工具兼容，例如 OpenAI Codex、Anthropic 的 Claude Code、Google DeepMind 的 Gemini CLI 以及 Cursor。

本仓库中的技能遵循标准化的 [Agent Skills](https://agentskills.io/home) 格式。

> [!NOTE]
> **只想让你的智能体访问 Hugging Face Hub？** 请先从 [`hf-cli`](https://huggingface.co/docs/hub/agents-cli) 开始。它是推荐安装的首选技能：它会教会你的智能体所有 `hf` 命令（搜索模型、管理数据集和存储桶、部署 Spaces、运行作业），并且它是根据你本地安装的 CLI 生成的，因此能始终保持最新。

## 技能如何工作？

在实际使用中，技能是包含指令、脚本和资源的独立文件夹，供 AI 智能体在特定用例中调用。每个文件夹都包含一个带有 YAML frontmatter（名称和描述）的 `SKILL.md` 文件，后面跟着你的编码智能体在激活该技能时遵循的指导说明。 

> [!TIP]
> 如果你的智能体不支持技能，你可以直接使用 [`agents/AGENTS.md`](agents/AGENTS.md) 作为备用方案。

本仓库中的技能还可通过以下渠道获取：
 - Cursor Marketplace（https://cursor.com/marketplace/huggingface）
 - Codex 插件目录（https://developers.openai.com/codex/plugins）

## 安装

Hugging Face 技能与 Claude Code、Codex、Gemini CLI 和 Cursor 兼容。

### Claude Code

1. 将本仓库注册为插件市场：  
   
```
/plugin marketplace add huggingface/skills
```

2. 安装技能时运行：  
   
```
/plugin install <skill-name>@huggingface/skills
```

例如：  

```
/plugin install hf-cli@huggingface/skills
```

### Codex

1. 根据 [Codex Skills 指南](https://developers.openai.com/codex/skills/) 中的说明，将本仓库 `skills/` 目录中你想使用的任何技能复制或以符号链接形式放入 Codex 的标准 `.agents/skills` 位置之一（例如 `$REPO_ROOT/.agents/skills` 或 `$HOME/.agents/skills`）。

2. 当技能位于上述任一位置后，Codex 将使用 Agent Skills 标准自动发现它，并在决定使用该技能或你显式调用时加载 `SKILL.md` 中的指令。

3. 如果你的 Codex 配置仍依赖 `AGENTS.md`，你可以使用本仓库中生成的 [`agents/AGENTS.md`](agents/AGENTS.md) 文件作为备用指令包。

### Gemini CLI

1. 本仓库包含 `gemini-extension.json`，用于与 Gemini CLI 集成。

2. 本地安装：  

```
gemini extensions install . --consent
```

或使用 GitHub URL：

```
gemini extensions install https://github.com/huggingface/skills.git --consent
```

4. 更多帮助请参阅 [Gemini CLI 扩展文档](https://geminicli.com/docs/extensions/#installing-an-extension)。

### Cursor

本仓库包含以下 Cursor 插件清单文件：

- `.cursor-plugin/plugin.json`
- `.mcp.json`（已配置 Hugging Face MCP 服务器 URL）

请通过 Cursor 的插件流程，从仓库 URL（或本地克隆路径）进行安装。

对于贡献者，请使用以下命令重新生成清单：

```bash
./scripts/publish.sh
```

### 在你的编码智能体中使用技能

安装技能后，在给你的编码智能体下达指令时直接提及它即可：

- “使用 HF LLM trainer 技能估算运行 70B 模型所需的 GPU 显存。”
- “使用 HF model evaluation 技能在最新 checkpoint（检查点）上启动 `run_eval_job.py`。”
- “使用 HF dataset creator 技能起草新的 few-shot（少样本）分类模板。”
- “使用 HF paper publisher 技能索引我的 arXiv 论文并将其链接到我的模型。”

你的编码智能体在执行任务时会自动加载对应的 `SKILL.md` 指令和辅助脚本。

### 贡献或自定义技能

1. 复制一个现有的技能文件夹（例如，`hf-datasets/`）并重命名。
2. 更新新文件夹的 `SKILL.md` frontmatter：
   ```markdown
   ---
   name: my-skill-name
   description: Describe what the skill does and when to use it
   ---

   # Skill Title
   Guidance + examples + guardrails
   ```
3. 添加或编辑你的指令中引用的辅助脚本、模板和文档。
4. 在 `.claude-plugin/marketplace.json` 中添加一条条目，并提供简洁易懂的描述。
5. 运行：
   ```bash
   ./scripts/publish.sh
   ```
   以重新生成并验证所有生成的元数据。
6. 在你的编码智能体中重新安装或重载技能包，以便使用更新后的文件夹。

### 插件市场

`.claude-plugin/marketplace.json` 文件列出了技能及其面向插件市场的易读描述。CI 会验证 `SKILL.md` 文件和 `marketplace.json` 之间的技能名称与路径是否匹配，但描述内容分别维护：`SKILL.md` 中的描述用于指导 Claude 何时激活该技能，而市场描述则是为浏览可用技能的开发者编写的。
